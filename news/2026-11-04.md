## 1. Claude Code 2.1.318 为分叉任务加入独立推理强度，并修复长会话续跑

![Claude Code 2.1.318 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.318)

*图片来源：[Anthropic Claude Code 官方 GitHub 发布页](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)*

Claude Code 2.1.318 为 Mod 的 `$.model.fork` 增加独立 `effort` 参数，使轻量分支任务可在主会话保持高推理强度时单独使用低强度，并在结果中回报实际强度。版本同时修复 `--continue` 在畸形工具调用重试耗尽后丢失历史、macOS 多 Bash 进程导致内存增长与停滞，以及多个终端共享登录状态时任务误报未登录等问题。它还为 Mod 启用询问保留用户回答记录，并公开登录到期时间与提前警告。

**为什么值得关注：** 分支任务的独立算力控制让智能体能按任务难度分配成本；续跑历史、并发登录和配置写锁的修复，则直接改善多终端、长会话开发的可靠性。

- **原文：** [Claude Code v2.1.318 Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)
- **发布日期：** 2026-11-04
- **时间范围：** 过去 24 小时

## 2. Qwen Code 0.26.7 统一 ACP 执行循环并隔离不可信 PR

![Qwen Code 0.26.7 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/QwenLM/qwen-code/releases/tag/v0.26.7)

*图片来源：[Qwen Code 官方 GitHub 发布页](https://github.com/QwenLM/qwen-code/releases/tag/v0.26.7)*

Qwen Code 0.26.7 让 ACP Goal、定时任务和后台通知在启用实验性统一循环后共享轮次、工具批次与停止点，并允许托管智能体在创建会话时传入完整模型配置。新增的 `/verify-pr` Docker 配方可在容器内运行不可信 PR 代码，同时通过主机侧聊天代理保留模型凭据；绑定 PR 的 GitHub 事件也会以“不可信提示”进入对应会话，回复默认保持私有。版本还要求在执行仓库自带钩子、权限授权和语言服务器前明确授予文件夹信任。

**为什么值得关注：** 它把调度任务、ACP 目标和交互会话收敛到同一执行语义，并为“让智能体验证外部 PR”建立凭据不入容器、仓库指令不默认可信的安全边界。

- **原文：** [Qwen Code v0.26.7 Release](https://github.com/QwenLM/qwen-code/releases/tag/v0.26.7)
- **发布日期：** 2026-11-04
- **时间范围：** 过去 24 小时

## 3. Hermes Agent 0.22.7 推进群聊式多智能体协作与共享任务面板

![Hermes Agent 0.22.7 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.7)

*图片来源：[Nous Research Hermes Agent 官方 GitHub 发布页](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.7)*

Hermes Agent 0.22.7 汇总自 0.22.6 以来约 174 个合并 PR，覆盖 CLI、安装器、Microsoft Store、Docker 与 Hermes Cloud。官方列出的增量包括桌面群聊的可选 Lead 路由、向群聊投递结果的定时任务、房间目的与共享笔记、成员实时状态，以及可固定为快速切换标签的 Kanban 看板；另外加入 Slack 线程静默策略、Team Gateway 的 Telegram 账号链接和更多插件目录项。完整整理后的说明仍计划随 0.23.0 发布，因此本条仅采用当前发布页明确列出的功能。

**为什么值得关注：** Hermes 正把多智能体协作从后台委派推进为可观察、可路由、带共享状态和任务板的团队工作空间，这更接近真实软件团队的协作模型。

- **原文：** [Hermes Agent v0.22.7 Release](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.7)

## 4. OpenHands 1.35.0 强化事件自动化、会话恢复与实时可观察性

![OpenHands 1.35.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/OpenHands/OpenHands/releases/tag/v1.35.0)

*图片来源：[OpenHands 官方 GitHub 发布页](https://github.com/OpenHands/OpenHands/releases/tag/v1.35.0)*

OpenHands 1.35.0 为自动化加入事件 Webhook 来源视图、按来源列出事件类型、可编辑的 `keep_alive`，并把工作区与仓库元数据持久化为服务器端会话标签。Agent Canvas 现在可显示实时智能体状态、启动与恢复详情，并把钩子、推理和工具调用按活动组合；同时修复暂停沙箱恢复、初始云端历史重试、附件跨导航传递及短暂会话故障。版本也允许在运行时不可用时直接加载保存的历史，减少恢复旧会话对执行环境的依赖。

**为什么值得关注：** 面向生产的开发智能体不仅要“能执行”，还必须能从事件触发、跨运行时恢复并解释正在做什么；这次更新把自动化与可观察性放在同一条链路上。

- **原文：** [OpenHands v1.35.0 Release](https://github.com/OpenHands/OpenHands/releases/tag/v1.35.0)
- **发布日期：** 2026-11-03
- **时间范围：** 过去 24 小时

## 5. Factory Droid 1.2.0 降低大工具集延迟并修复远程 MCP 登录

![Factory Droid 1.2.0 官方更新日志](https://image.thum.io/get/width/1200/crop/675/noanimate/https://docs.factory.com/changelog/release-notes)

*图片来源：[Factory 官方更新日志](https://docs.factory.com/changelog/release-notes)*

Factory Droid 1.2.0 缩短数百个工具同时可用时的回复与非交互执行启动时间，并让智能体发起的任务继承当前运行的权限跳过设置，避免后台任务卡在重复审批。远程会话添加 OAuth MCP 服务器时现在可通过本地浏览器完成登录，macOS 在大量 Skill 文件下不再卡住，失败连接也会遵守重试上限。版本还修复端口转发大文件上传的字节丢失与内存增长，并对公共 API 的畸形标识符增加显式校验。

**为什么值得关注：** 大规模工具目录、远程机器和后台任务是企业智能体常见部署形态；这些改动同时处理启动性能、审批继承、OAuth 跳转和重连失控，减少无人值守执行的系统性卡点。

- **原文：** [Factory Droid CLI/Desktop v1.2.0 Release Notes](https://docs.factory.com/changelog/release-notes)
- **发布日期：** 2026-11-03
- **时间范围：** 扩展至过去 72 小时（官方未给出精确发布时间）
