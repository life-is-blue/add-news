## 1. Letta Code 0.34.38 为每个子智能体任务保存完整 JSONL 事件日志

![Letta Code 0.34.38 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/letta-ai/letta-code/releases/tag/v0.34.38)

*图片来源：Letta Code 官方 GitHub Release（页面截图）*

Letta Code 0.34.38 会把子智能体的进度持续写入任务输出文件，并为每个任务保存完整 JSONL 事件日志，远程 worker 也包含在内。日志与实时进度分离，使主智能体既能消费当前状态，也能在任务结束后审计事件序列。版本同时调整公开示例，避免把内部名称和 ID 当作稳定公共接口。

**为什么值得关注：** 多智能体协作最难排查的往往不是最终结果，而是委派期间发生了什么；结构化事件日志为失败复盘、远程 worker 诊断和自动验收提供了可机器读取的证据链。

- **原文：** [Letta Code v0.34.38 Release](https://github.com/letta-ai/letta-code/releases/tag/v0.34.38)
- **发布日期：** 2026-11-02 15:09（新加坡时间；过去 24 小时）

## 2. Senpi 2026.11.02-1 修复 Claude 登录，并稳定 MCP 工具顺序与多账户切换

![Senpi 2026.11.02-1 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/code-yeongyu/senpi/releases/tag/v2026.11.02-1)

*图片来源：Senpi 官方 GitHub Release（页面截图）*

Senpi 2026.11.02-1 修复 Claude CLI 用终端格式输出时，已成功登录却被误判为异常退出的问题，并只接受 Claude 登录域名上的 HTTPS 链接。MCP 工具现在保持稳定顺序，不再因服务器连接先后而改变；CJK 会话压缩也按文本特性调整切分权重，使保留 token 更接近配置值。多账户场景中，被拒绝或已撤销的账号会先被阻断，再在生成输出前切换到同提供方的可用账号。

**为什么值得关注：** 登录、工具顺序、上下文压缩和账号故障转移都是长程智能体的隐性状态；这些修复减少了同一任务在不同运行时机出现不可复现行为的概率。

- **原文：** [Senpi v2026.11.02-1 Release](https://github.com/code-yeongyu/senpi/releases/tag/v2026.11.02-1)
- **发布日期：** 2026-11-02 11:25（新加坡时间；过去 24 小时）

## 3. Oh My Pi 18.15.0 修复 Codex 远程压缩回放与后台任务状态丢失

![Oh My Pi 18.15.0 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/can1357/oh-my-pi/releases/tag/v18.15.0)

*图片来源：Oh My Pi 官方 GitHub Release（页面截图）*

Oh My Pi 18.15.0 修复 OpenAI 远程压缩回放时夹带后端内部元数据、导致 Codex 拒绝请求的问题，并在重新构造输入时剔除这些字段。后台结果在手动压缩期间不再从保存会话中消失，Snapcompact 对已有归档的再次压缩也能正确判断收益。版本还让无可用凭据的模型自动切换到有凭据的回退链候选，并在凭据恢复后的下一轮切回。

**为什么值得关注：** 压缩、恢复和模型回退是超长编码任务最容易断链的位置；这组修复直接提升了 Codex 会话跨压缩继续执行的可靠性。

- **原文：** [Oh My Pi v18.15.0 Release](https://github.com/can1357/oh-my-pi/releases/tag/v18.15.0)
- **发布日期：** 2026-11-01 22:17（新加坡时间；过去 24 小时）

## 4. Rig 0.46.0 将 MCP、ACP、Skills 与流量审计拆成可组合插件

> **时间范围：扩展至过去 72 小时**

![Rig 0.46.0 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/0xPlaygrounds/rig/releases/tag/v0.46.0)

*图片来源：Rig 官方 GitHub Release（页面截图）*

Rig 0.46.0 新增默认关闭的 MCP 客户端插件，支持 stdio 与 Streamable HTTP，并要求项目级服务器按原始配置显式批准后才启动。新的 ACP 插件可让 Zed、Neovim 等 ACP v1 客户端使用 Rig 的模型、工具、权限、会话和历史回放；同时加入 AGENTS.md、Agent Skills、数据库会话存储与会话格式迁移。流量插件可把经过清理、带版本的模型提供方交互写入逐行 JSON 日志，便于审计。

**为什么值得关注：** 这次发布展示了一种轻量编排器的模块化路线：协议接入、上下文规范、持久化、审批和审计彼此独立，却能组合成完整编码智能体运行时。

- **原文：** [Rig v0.46.0 Release](https://github.com/0xPlaygrounds/rig/releases/tag/v0.46.0)

## 5. Google Antigravity CLI 1.4.12 支持可选 API Key 插件认证

> **时间范围：扩展至过去 72 小时**

![Antigravity CLI 1.4.12 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.12)

*图片来源：Google Antigravity CLI 官方 GitHub Release（页面截图）*

Antigravity CLI 1.4.12 允许插件在 `auth.json` 中把 API Key 提供方标记为可选。未配置密钥时，插件命令会把变量视为未设置并使用服务的匿名免费额度，不再直接报 401 或强制登录。版本还修复长流式回复中的 Markdown 表格在终端滚动区出现边框错位和重复文本的问题。

**为什么值得关注：** 可选认证让同一插件能在“匿名低额度”和“带密钥高额度”之间自然退化，减少了智能体插件因凭据缺失而整体失败的脆弱性。

- **原文：** [Google Antigravity CLI 1.4.12 Release](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.12)
- **发布日期：** 2026-10-31 05:39（新加坡时间；过去 72 小时）
