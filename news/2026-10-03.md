## 1. Claude Code 2.1.288：长会话恢复、权限钩子与 Agent Teams 同步加固

![Claude Code 2.1.288 官方发布页截图](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.288)

*图片来源：[Anthropic Claude Code 官方 GitHub 发布页](https://github.com/anthropics/claude-code/releases/tag/v2.1.288)*

Anthropic 发布 Claude Code 2.1.288，Mods 新增读取最近选中文本的接口，云端会话获得内置 `gh api`，代码审查可用 `--max-findings` 调整问题数量，MCP 工具在执行中申请更大 OAuth 范围时也会触发重新认证。可靠性修复覆盖长对话未自动压缩、`--resume` 丢失文件或思考过程、远程 MCP 结果过大时工具调用重复，以及 Agent Teams 中插件定义智能体未使用自身提示词、工具和 effort 配置等问题。安全边界同时收紧：危险 `rm` 藏在 `bash -c` 中不再绕过确认，PreToolUse 或 PermissionRequest 钩子匹配失败时改为阻断调用。

**为什么值得关注：** 这次更新没有停留在界面功能，而是集中修补长时运行、团队智能体配置继承和“失败时放行”等生产级风险，直接提升 Claude Code 作为自主开发运行时的可信度。

- **原文：** [Claude Code 2.1.288 release](https://github.com/anthropics/claude-code/releases/tag/v2.1.288)
- **发布日期：** 2026-10-02

## 2. OpenClaw 2026.9.8：修复委派结果丢失，并明确取消智能体自动来回对话

![OpenClaw 2026.9.8 官方发布说明截图](https://image.thum.io/get/width/1200/crop/675/noanimate/https://docs.openclaw.ai/releases/2026.9.8)

*图片来源：[OpenClaw 官方发布说明](https://docs.openclaw.ai/releases/2026.9.8)*

OpenClaw 2026.9.8 纳入 43 个 PR，新增 GPT-6.1 Sol 路由，并修复 Codex 大规模配置下的内存占用、Windows 更新与启动、连接策略热重载期间任务中断等问题。多智能体方面，委派结果现在会以原始请求者身份准确返回一次；内部会话不再允许以 `NO_REPLY` 静默结束，自动 peer ping-pong 与目标公告循环被移除，后续协作必须显式调用 follow-up 或消息工具。版本还加强网关状态独占、TLS 指纹检查、Bun 日志脱敏和只读安装中的 Skill 刷新。

**为什么值得关注：** OpenClaw 正在把隐式“智能体互聊”收束为显式、可追踪的消息传递，这对三层协作中的任务交接、结果归属与避免失控循环尤其关键。

- **原文：** [OpenClaw 2026.9.8 release](https://github.com/openclaw/openclaw/releases/tag/v2026.9.8)
- **详细说明：** [OpenClaw v2026.9.8 release notes](https://docs.openclaw.ai/releases/2026.9.8)
- **发布日期：** 2026-10-03

## 3. GitHub 将 Copilot 代码评审开放给 REST 与 GraphQL API

![Copilot 代码评审 API 官方公告截图](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level/)

*图片来源：[GitHub 官方公告](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level/)*

GitHub 现在允许通过 REST 和 GraphQL API 请求 Copilot 代码评审，并能为每次请求单独指定 review effort；该能力已对 Pro、Pro+、Max、Business 与 Enterprise 套餐正式开放。团队可以从自有脚本、CI 工作流或内部平台主动触发评审，而不必依赖 GitHub 网页操作。与此同时，Balanced 已成为新旧仓库及组织的默认评审强度，显式选择 Lite 的配置则保持不变。

**为什么值得关注：** 独立验收智能体终于获得标准化触发接口，架构智能体、实现智能体和评审智能体之间可以形成真正自动化、可审计的闭环。

- **原文：** [Copilot code review: API support and new default effort level](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level/)
- **发布日期：** 2026-10-02

## 4. GitHub Copilot 淘汰四款旧模型，智能体工作流需主动迁移

![GitHub Copilot 模型弃用公告截图](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated/)

*图片来源：[GitHub 官方公告](https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated/)*

GitHub 在全部 Copilot 体验中弃用 Gemini 3.5 Flash、Gemini 3.6 Flash、Kimi K2.7 Code 与 Claude Opus 4.7，范围包括聊天、内联编辑、Ask、Agent Mode 和代码补全。官方建议分别迁移到 Gemini 3.8 Flash、Kimi K3 和 Claude Opus 5.5；企业管理员还需确认替代模型已在 Copilot 模型策略中启用。平台会自动移除旧模型，但依赖固定模型名的工作流和集成仍需人工更新。

**为什么值得关注：** 编码智能体的模型层正在快速轮换，可靠编排不能再把模型 ID 写死；能力探测、路由回退和企业策略校验应成为 Harness 的基础设施。

- **原文：** [Selected models in GitHub Copilot deprecated](https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated/)
- **发布日期：** 2026-10-02

## 5. 六家头部公司签署自愿 AI 安全协议，但缺少强制执行机制

![美国 AI 安全协议相关新闻截图](https://image.thum.io/get/width/1200/crop/675/noanimate/https://www.reuters.com/legal/litigation/public-fears-ai-grow-trump-digs-voluntary-safeguards-2026-10-03/)

*图片来源：[Reuters](https://www.reuters.com/legal/litigation/public-fears-ai-grow-trump-digs-voluntary-safeguards-2026-10-03/)*

美国政府与 Nvidia、SpaceX、OpenAI、Anthropic、Meta 和 Google 达成一页式自愿安全协议，提出建立防止未授权入侵的内部控制，并与独立外部审计方合作。路透社指出，协议没有写明企业不履约时的后果，也未给出具体执行和监督机制；支持者认为它至少承认了高级 AI 的安全风险，批评者则担心审计若仍向企业自身汇报就难以独立。该协议出台之际，智能体越权和外部系统访问事件正推动监管与审计进入实际产品治理。

**为什么值得关注：** 对联网编码智能体而言，权限控制、外部审计与事故责任正在从内部工程规范上升为公共政策议题；但自愿承诺能否转化为可验证控制，仍是最大的未知数。

- **原文：** [Reuters：As public fears of AI grow, Trump digs in on voluntary safeguards](https://www.reuters.com/legal/litigation/public-fears-ai-grow-trump-digs-voluntary-safeguards-2026-10-03/)
- **发布日期：** 2026-10-03
