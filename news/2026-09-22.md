## 1. Z.ai 停用 ZCode 部分功能：默认索引被曝上传本地代码库

![Z.ai ZCode 安全事件报道](https://image.thum.io/get/width/1200/crop/675/noanimate/https://indianexpress.com/article/technology/artificial-intelligence/chinas-z-ai-disables-ai-coding-assistant-features-after-security-issue-10888434/)

*图片来源：[Reuters／The Indian Express](https://indianexpress.com/article/technology/artificial-intelligence/chinas-z-ai-disables-ai-coding-assistant-features-after-security-issue-10888434/)*

Reuters 报道，Z.ai 在用户反映 ZCode 会未经同意把本地代码库上传至云端后，停用了这款编码助手的部分功能。公司称问题源自默认开启的 “Codebase Indexing”，已修补漏洞、删除相关数据、启用零数据保留并承诺建立持续漏洞响应机制；独立评估称云平台未保留代码，但完整报告尚未公开。Z.ai 还将 ZCode 开源，邀请开发者继续审查。

**为什么值得关注：** 编码智能体天然需要读取整个仓库，索引功能一旦默认联网就可能把源代码、凭据和个人信息带出安全边界；“默认最小上传、可验证删除、明确开关”应成为企业采用的硬要求。

- **原文：** [China’s Z.ai disables AI coding assistant features after security issue](https://indianexpress.com/article/technology/artificial-intelligence/chinas-z-ai-disables-ai-coding-assistant-features-after-security-issue-10888434/)
- **产品核验：** [ZCode 官方页面](https://zcode.z.ai/)
- **发布日期：** 2026-09-22（过去 24 小时）

## 2. Hermes Agent 0.21.4 发布：补齐网关单例、JSONL 输出与技能常驻

![Hermes Agent 0.21.4 发布页](https://opengraph.githubassets.com/1/NousResearch/hermes-agent/releases/tag/v2026.9.21)

*图片来源：[NousResearch 官方 GitHub 发布页](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.9.21)*

Hermes Agent 0.21.4 是面向 Docker、Hermes Cloud 与托管部署的稳定补丁版本；官方统计其自 0.21.3 起合并了 1,812 个 PR、涉及 5,071 个非合并提交。发布说明列出的改动包括宿主机级网关单例锁、CLI 的 `--format stream-json` 结构化 JSONL 输出、`skills.auto_load`、未授权私信拒绝策略、MCP 发现并发上限，以及 profile、cron、kanban 和状态数据库修复。完整整理版说明被推迟到 0.22.0。

**为什么值得关注：** JSONL 输出、技能常驻和网关单例都直接服务于可编排的长期运行智能体；但“补丁版”承载如此大的变更量，也提醒生产部署者必须加强灰度升级与回归验证。

- **原文：** [Hermes Agent v0.21.4 官方发布说明](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.9.21)
- **发布日期：** 2026-09-21 18:10 UTC（过去 24 小时）

## 3. OpenClaw 发布 2026.7.35 Extended Stable，修复 Doctor 插件注册表损坏

![OpenClaw 2026.7.35 发布页](https://opengraph.githubassets.com/1/openclaw/openclaw/releases/tag/v2026.7.35)

*图片来源：[OpenClaw 官方 GitHub 发布页](https://github.com/openclaw/openclaw/releases/tag/v2026.7.35)*

OpenClaw 2026.7.35 是仅面向网关的 Extended Stable 版本，官方将其定位为当前等同 LTS 的维护线；它基于 2026 年 7 月代码，并回移关键安全、可靠性、性能和模型支持更新，最新版仍为 2026.9.5。此次新增修复确保 Doctor 创建或修复注册状态时保留完整的内置插件清单，并能从 2026.7.34 写出的不完整注册表恢复，同时保留外部插件安装记录。官方称这项补丁来自对上一审计游标之后 1,418 个提交的复核。

**为什么值得关注：** 对承担浏览器、文件传输、配对与语音等能力的网关而言，插件注册表缺失会造成“重启后能力静默消失”；独立稳定维护线让组织能获得关键修复而不必追随快速主线。

- **原文：** [OpenClaw 2026.7.35 官方发布说明](https://github.com/openclaw/openclaw/releases/tag/v2026.7.35)
- **发布日期：** 2026-09-21 13:14 UTC（过去 24 小时）

## 4. Aikido 推出本地运行的安全模型 Altar，避免敏感代码外送

![Aikido Altar 安全模型报道](https://image.thum.io/get/width/1200/crop/675/noanimate/https://www.reuters.com/legal/litigation/belgiums-aikido-launches-cybersecurity-ai-model-demand-local-tools-grows-2026-09-21/)

*图片来源：[Reuters](https://www.reuters.com/legal/litigation/belgiums-aikido-launches-cybersecurity-ai-model-demand-local-tools-grows-2026-09-21/)*

比利时安全公司 Aikido 发布开放权重模型 Altar，面向漏洞发现等网络安全任务，并支持在本地部署，使企业无需把敏感代码发送给外部模型提供商。Reuters 报道称，Altar 是对 Z.ai 开放模型 GLM-5.3 的压缩与定制版本，并将进入 Aikido 为 Belfius 等客户提供的产品。该发布反映安全代码审查正同时追求智能体能力与数据驻留。

**为什么值得关注：** 在 ZCode 上传事件同日受到关注的背景下，本地开放权重路线提供了另一种企业安全架构：代码留在受控环境内，模型和审计工具靠近数据运行。

- **原文：** [Belgium’s Aikido launches cybersecurity AI model](https://www.reuters.com/legal/litigation/belgiums-aikido-launches-cybersecurity-ai-model-demand-local-tools-grows-2026-09-21/)
- **发布日期：** 2026-09-21 14:14 UTC（过去 24 小时）

## 5. 轨迹感知抽样把 SWE-Agent 回归测试 Token 成本削减约 90%

![SWE-Agent 轨迹感知回归测试研究](https://image.thum.io/get/width/1200/crop/675/noanimate/https://arxiv.org/abs/2609.24928)

*图片来源：[arXiv 论文页面](https://arxiv.org/abs/2609.24928)*

新论文提出用智能体执行轨迹的嵌入空间选择软件工程基准子集，替代随机或仅按历史成败分层的抽样方法。作者在相同配置复跑、模型或配置变化、智能体框架变化三类回归场景中比较了 76 种选择方案；最佳方法按历史结果分组后选择靠近组内质心的任务。实验显示，10% 的轨迹感知子集可将中位估计误差控制在 5% 以下，同时把 Token 成本降低约 90%。

**为什么值得关注：** 编码智能体快速迭代后，全量 SWE 基准会成为持续集成的成本瓶颈；利用既有轨迹挑选代表性回归集，可能让模型、Harness 和提示词的每次变更都能获得更频繁的质量反馈。

- **原文：** [Trajectory-Aware Benchmark Subset Selection for Cost-Efficient Software Engineering Agent Regression Testing](https://arxiv.org/abs/2609.24928)
- **发布日期：** 2026-09-21 17:23 UTC（过去 24 小时）
