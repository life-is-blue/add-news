*图片来源：[OpenClaw 官方发布说明](https://docs.openclaw.ai/releases/2026.11.8)*

OpenClaw 发布 2026.11.8，规模为 210 个 PR、104 个直接提交和 86 名贡献者，重点修复聊天、更新、模型与自动化可靠性。安全方面，版本阻止一次性 Signal 附件进入智能体输入、拦截工作区 Azure 重定向、清理反射出的 ClawHub 凭据，并拒绝 Windows 命令中的换行注入。自动化方面则修复跨账户任务历史、PostgreSQL 16 的一次性任务收尾、隔离任务的 scratch notes，以及本地 Codex `/goal` 会话提前停止等问题。

## 4. Google Antigravity 接入 MCP Apps：智能体工具从文本响应升级为交互界面

![Antigravity MCP Apps 官方介绍](https://image.thum.io/get/width/1200/crop/675/noanimate/https://antigravity.google/blog/mcp-apps-in-antigravity)

*图片来源：[Google Antigravity 官方博客](https://antigravity.google/blog/mcp-apps-in-antigravity)*

Google Antigravity 宣布支持 MCP Apps，允许工具在聊天内联卡片、侧边面板、全页视图和自定义文件查看器四种界面中呈现交互内容。Vercel 示例可在聊天中展示部署卡片、把预览链接重新加入提示，并启动共享 Sandbox Desktop 让开发者与智能体并排测试桌面和移动布局。文件型入口使用不暴露真实路径的 `antigravity-file://` URI，并仅在本地文件场景授予保存回写能力；首批生态还包括 Better Stack、CodeRabbit、Datadog、monday.com 和 Qodo。

**为什么值得关注：** MCP 正从“调用工具的协议”扩展为智能体与人共同操作的 UI 层；这会显著改善部署、监控、审查和项目协作中的证据展示与人工确认。

- **原文：** [Bringing MCP Apps to Antigravity](https://antigravity.google/blog/mcp-apps-in-antigravity)
- **发布日期：** 2026-11-24

## 5. OpenAI 与 Cisco 开源 Shirudo：Codex 生成 eBPF 临时防护并由人批准部署

![OpenAI 与 Cisco 推出 Shirudo](https://image.thum.io/get/width/1200/crop/675/noanimate/https://openai.com/index/introducing-shirudo/)

*图片来源：[OpenAI 官方公告](https://openai.com/index/introducing-shirudo/)*

OpenAI 与 Cisco 发布开源运行时 Shirudo，用 eBPF 为仍在等待正式补丁的 Linux 服务部署临时“盾牌”，无需重启系统。智能体可调查漏洞、生成针对性防护并用真实攻击与正常负载验证效果，但最终部署仍由安全团队控制；防护会经过密码学签名、eBPF Verifier 检查，并可借助 TPM 留下可验证记录。在受控测试中，Codex 生成的防护阻止了运行中 Elasticsearch 服务遭受 Java4Shell 利用，同时没有中断服务。

**为什么值得关注：** 这是编码智能体从修复源代码进一步进入运行中基础设施的案例，同时把测试、签名、内核验证和人工批准纳入部署链，展示了高风险自主操作应有的安全结构。

- **原文：** [OpenAI and Cisco introduce Shirudo](https://openai.com/index/introducing-shirudo/)
- **交叉核验：** [Cisco 官方公告](https://newsroom.cisco.com/c/r/newsroom/en/us/a/y2026/m11/cisco-and-openai-launch-shirudo-a-new-project-to-safeguard-agentic-ai.html)
- **发布日期：** 2026-11-23
- **时效：** **扩展至过去 72 小时**
