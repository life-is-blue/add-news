## 1. Agent Relay 18.2–18.3 为 Webhook 唤醒加入恢复扫描与会话建频道

![Agent Relay v18.3.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/AgentWorkforce/relay/releases/tag/v18.3.0)

*图片来源：[Agent Relay 官方 GitHub 发布页](https://github.com/AgentWorkforce/relay/releases/tag/v18.3.0)*

Agent Relay 在数小时内连续发布 18.2.0 与 18.3.0：18.2.0 提供单一 MCP URL，让每次 Webhook 请求都能唤醒一个空闲智能体，并允许会话创建、订阅协作频道。连接命令增加延长会话与恢复云端已关闭房间的能力。18.3.0 随后加入“卡住唤醒”的恢复扫描，并澄清 Webhook 监听步骤。

**为什么值得关注：** 事件驱动智能体的薄弱点往往不是接收 Webhook，而是唤醒丢失后无人补偿；恢复扫描、频道创建和房间重连共同补上了多智能体协作的可靠性闭环。

- **原文：** [Agent Relay v18.3.0](https://github.com/AgentWorkforce/relay/releases/tag/v18.3.0)；[v18.2.0](https://github.com/AgentWorkforce/relay/releases/tag/v18.2.0)
- **发布日期：** 2026-11-12
- **时间范围：** 过去 24 小时

## 2. Chrome DevTools MCP 1.13.0 加入页面级网络 Mock 与无侵入 Logpoint

![Chrome DevTools MCP 1.13.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/ChromeDevTools/chrome-devtools-mcp/releases/tag/chrome-devtools-mcp-v1.13.0)

*图片来源：[Chrome DevTools MCP 官方 GitHub 发布页](https://github.com/ChromeDevTools/chrome-devtools-mcp/releases/tag/chrome-devtools-mcp-v1.13.0)*

Chrome DevTools MCP 1.13.0 新增基于 DevTools BreakpointManager 的 Logpoint，可在不中断页面执行的情况下采集运行时信息。版本还支持页面作用域的网络 Mock 与上游 Mock 响应，便于智能体隔离接口行为并复现边界条件。与此同时，它修复二进制请求体保存、无图形环境启动提示和循环错误链等问题，并降低网络采集器的内存占用。

**为什么值得关注：** 浏览器智能体现在不仅能“看页面、点按钮”，还能主动构造网络条件并观测运行时状态；这让端到端调试和回归验证更接近可重复的软件测试，而不是脆弱的 UI 演示。

- **原文：** [Chrome DevTools MCP v1.13.0 Release](https://github.com/ChromeDevTools/chrome-devtools-mcp/releases/tag/chrome-devtools-mcp-v1.13.0)
- **发布日期：** 2026-11-11
- **时间范围：** 过去 24 小时

## 3. Qwen Code 1.0 Preview 合并 Qoder Harness，并首次提供免 Node.js 原生包

![Qwen Code 1.0 Preview 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/QwenLM/qwen-code/releases/tag/v1.0.0-preview)

*图片来源：[Qwen Code 官方 GitHub 发布页](https://github.com/QwenLM/qwen-code/releases/tag/v1.0.0-preview)*

Qwen Code 1.0 Preview 把 Qoder 的智能体能力与 Qwen Code 合并，用于代码理解、实现、调试和测试。它同时支持 Qwen、Qoder 账户，多种模型提供商及兼容端点，并首次提供 macOS、Linux、Windows 原生包，无需单独安装 Node.js。新版本还保留会话续跑与非交互执行，面向持续开发和脚本化自动化。

**为什么值得关注：** 把 IDE 内部验证过的 Harness 下沉到开源 CLI，并降低本地安装门槛，会扩大可复用编码智能体运行时的受众；但 Preview 阶段的接口和行为仍可能变化。

- **原文：** [Qwen Code v1.0.0-preview Release](https://github.com/QwenLM/qwen-code/releases/tag/v1.0.0-preview)
- **发布日期：** 2026-11-11
- **时间范围：** 扩展至过去 72 小时

## 4. 官方 MCP Servers 2.4.0 一次修复六项文件、Git 与网络边界漏洞

![MCP Servers 2.4.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/modelcontextprotocol/servers/releases/tag/v2.4.0)

*图片来源：[Model Context Protocol 官方 GitHub 发布页](https://github.com/modelcontextprotocol/servers/releases/tag/v2.4.0)*

MCP Servers 2.4.0 修复三个服务器中的六项漏洞：Filesystem 阻止检查后目录被替换为符号链接，以及不安全的跨目录移动；Git Server 禁止不可信仓库通过本地 Git 配置执行程序，并收紧对象存储和 worktree 边界。Fetch Server 同时修补 IPv6 私网识别和 robots.txt 路径规范化绕过，官方还提醒旧的日期版本用户必须显式安装 Filesystem 2.3.0，因为包管理器不会自动把它视为升级。

**为什么值得关注：** MCP 工具通常继承宿主机权限，这些漏洞能把看似只读的仓库或文件操作升级为越界读取、命令执行或内网访问；明确版本与升级陷阱对生产部署尤为关键。

- **原文：** [MCP Servers v2.4.0 Release](https://github.com/modelcontextprotocol/servers/releases/tag/v2.4.0)
- **发布日期：** 2026-11-11
- **时间范围：** 扩展至过去 72 小时
- **升级提示：** Filesystem 旧日期版本需显式安装 `@modelcontextprotocol/server-filesystem@2.3.0`

## 5. MCP 与 Agent Skills 纳入 AAIF，由 Google、Anthropic、OpenAI 共同维护

![Google 关于 MCP 与 Agent Skills 加入 AAIF 的官方文章](https://image.thum.io/get/width/1200/crop/675/noanimate/https://opensource.googleblog.com/2026/11/scaling-ai-agents-open-standards-mcp-aaif.html)

*图片来源：[Google Open Source Blog 官方文章](https://opensource.googleblog.com/2026/11/scaling-ai-agents-open-standards-mcp-aaif.html)*

Google 确认，Anthropic 已将 Agent Skills 规范与 MCP 一并捐赠给 Linux Foundation 旗下 Agentic AI Foundation（AAIF）。来自 Google、Anthropic、OpenAI 及更广泛社区的工程师正以厂商中立方式共同维护标准；MCP 负责连接实时工具与数据，Agent Skills 则按需加载流程知识与脚本。文章同时指向 agentskills.io、规范仓库和 Google 的开发者技能目录，便于实现和参与治理。

**为什么值得关注：** 智能体生态正在把“工具协议”和“过程知识包”确立为互补的公共层；多家模型厂商共同治理，有望降低技能与工具被单一平台锁定的风险。

- **原文：** [Scaling AI agents with open standards](https://opensource.googleblog.com/2026/11/scaling-ai-agents-open-standards-mcp-aaif.html)
- **发布日期：** 2026-11-11
- **时间范围：** 扩展至过去 72 小时（官方页面未提供精确时刻，保守标注）
