## 1. OpenAI 将停止向 Cursor 提供模型，Claude 准备补位

![Cursor 标识](https://www.cursor.com/favicon.svg)

*图片来源：[Cursor 官方网站](https://www.cursor.com/)*

OpenAI 宣布，在 Cursor 被 SpaceX 收购后，将逐步终止向其提供模型，拟定停止日期为 2026 年 11 月 12 日，并表示未来模型 Astra 不会提供给 Cursor。OpenAI 将决定归因于对 SpaceX 能否遵守服务条款缺乏信心；Cursor 联合创始人 Michael Truell 表示双方仍在沟通，而 Anthropic 随后称将增加用于 Cursor 中 Claude 模型的算力支持。Reuters 对三方公开表态进行了交叉核验。

**为什么值得关注：** Cursor 的多模型策略依赖上游供应稳定性；这次变化说明，编码工具的模型路由不仅是技术与价格选择，也会受到所有权、合同和平台竞争影响，企业用户需要为模型退出准备可迁移的工作流。

- **原文：** [OpenAI：Our decision on Cursor following its acquisition by SpaceX](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/)
- **交叉核验：** [Reuters 报道](https://www.reuters.com/business/media-telecom/openai-end-partnership-with-spacexs-cursor-2026-08-29/)
- **发布日期：** 2026-08-28（Reuters 于 2026-08-29 持续更新）
- **时间窗口：** 过去 24 小时

## 2. GitHub 将云端智能体、网页与移动 Chat 统一为 Agent Sessions

![GitHub Copilot 改进公告](https://github.blog/wp-content/themes/github-2021-child/assets/img/featured-v3-improvements.svg)

*图片来源：[GitHub Changelog](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)*

GitHub 宣布最早于 9 月 28 日把 Copilot cloud agent、github.com Chat 和 GitHub Mobile Chat 合并为统一体验与统一策略，网页端将全面迁移到原本用于云智能体的 Agent Sessions。统一体验默认启用，Cloud agent 将使用 Sandbox 加速执行；聊天数据的保留期也会从 28 天改为账户生命周期。与此同时，Copilot Code Review 的默认推理强度将从 Lite 调整为 Balanced，企业管理员需提前审查权限、留存和成本影响。

**为什么值得关注：** 这不是单一 UI 更新，而是 GitHub 把“聊天”和“执行任务的智能体”合并为同一种持久会话；对企业而言，数据留存、默认开启和审查算力变化都需要纳入治理基线。

- **原文：** [GitHub：Upcoming changes to Copilot policies and billing](https://github.blog/changelog/2026-08-28-upcoming-changes-to-github-copilot-policies-and-billing/)
- **发布日期：** 2026-08-28
- **时间窗口：** 过去 24 小时

## 3. Copilot 跨 Slack、Teams 与 IDE 共享智能体会话，并引入“第二模型意见”

![GitHub Copilot 在 Slack 中的共享智能体会话](https://github.com/user-attachments/assets/a051e30f-c310-433d-8f4e-97b383f7c8d9)

*图片来源：[GitHub 官方发布说明](https://github.blog/changelog/2026-08-28-github-copilot-weekly-releases-august-24/)*

GitHub 本周更新允许团队在 Slack 或 Microsoft Teams 中通过 @GitHub 把讨论转成可共同跟踪和引导的智能体会话。VS Code 1.135 可继续来自其他应用的 Copilot 或 Claude agent sessions，并能调用互补模型给出“第二意见”，同时展示每轮对话的模型用量。Copilot App 的 Customize 页面也已全面可用，把 MCP servers、plugins、skills 与 canvases 集中在同一入口。

**为什么值得关注：** 编码智能体正从个人 IDE 助手变成跨沟通工具、桌面应用和 IDE 延续的团队状态机；“第二模型意见”则开始把多模型对抗验证产品化，接近架构—实现—验收的分层协作方式。

- **原文：** [GitHub Copilot weekly releases — August 24](https://github.blog/changelog/2026-08-28-github-copilot-weekly-releases-august-24/)
- **发布日期：** 2026-08-28
- **时间窗口：** 过去 24 小时

## 4. 腾讯开源 Hy4 Preview：770B MoE 面向编码、研究与金融任务

![Tencent Hy4 Preview](https://huggingface.co/tencent/Hy4-preview/resolve/main/assets/logo-en.png)

*图片来源：[腾讯 Hy4 Preview 官方模型卡](https://huggingface.co/tencent/Hy4-preview)*

腾讯在 Hugging Face 发布 Hy4 Preview，采用 7700 亿总参数、每个 token 激活约 490 亿参数的 Mixture-of-Experts 架构，并以 Apache 2.0 许可证开放权重。模型面向软件工程、研究与金融分析等生产力任务，支持 Transformers、vLLM 与 SGLang，腾讯计划把它接入 CodeBuddy 和 WorkBuddy。腾讯同时在模型卡中承认，预览版处理复杂问题时可能耗时过长并出现过度验证。

**为什么值得关注：** Hy4 把大规模开放权重模型直接瞄准智能体与编码场景，为本地部署和自主 harness 提供新的上游选择；但 49B 激活参数意味着其“开放”并不等于低成本运行，部署门槛仍然很高。

- **原文：** [Tencent Hy4 Preview 模型卡](https://huggingface.co/tencent/Hy4-preview)
- **交叉核验：** [Reuters 报道](https://www.reuters.com/world/asia-pacific/chinas-tencent-releases-new-open-source-ai-model-coding-research-tasks-2026-08-28/)
- **发布日期：** 2026-08-28
- **时间窗口：** 扩展至过去 72 小时

## 5. Claude 清理脚本误删约 700 GB：安全复核链本身成为故障点

![机械臂与高风险自动化示意图](https://cdn.mos.cms.futurecdn.net/rooXvESoBpBpBGCkrJPnwC.jpg)

*图片来源：[Tom’s Hardware / Getty Images](https://www.tomshardware.com/tech-industry/artificial-intelligence/claude-nukes-a-developers-700-gb-home-directory-while-testing-a-script-to-ensure-it-wouldnt-do-so-automatic-model-downgrade-may-have-contributed-to-the-screw-up)*

开发者 Sébastien Guillemot 公开称，他让 Claude 编写并对一个清理智能体临时目录的脚本进行对抗性复核，测试清理步骤因变量复用而误删其主目录，损失约 700 GB 数据及一周工作。Tom’s Hardware 根据开发者的原始记录还原称，风险检测触发后任务经历了模型降级，最终由较低级模型执行测试；开发者通过 Git、Nix 和会话日志恢复了大部分内容。Anthropic 尚未发布正式事故复盘，因此“模型降级导致事故”只能视为合理怀疑，不能当作已证实因果。

**为什么值得关注：** 事故说明“让另一个智能体做安全复核”并不自动形成隔离边界；删除、迁移和基础设施操作仍需要真实沙箱、路径白名单、快照备份以及由执行层强制的不可越权约束。

- **原文记录：** [开发者公开记录（由报道链接）](https://x.com/SebastienGllmt)
- **报道：** [Tom’s Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/claude-nukes-a-developers-700-gb-home-directory-while-testing-a-script-to-ensure-it-wouldnt-do-so-automatic-model-downgrade-may-have-contributed-to-the-screw-up)
- **发布日期：** 2026-08-28
- **时间窗口：** 扩展至过去 72 小时
