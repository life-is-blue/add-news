## 1. Anthropic 推出 Claude Ship：把代码审查推进到修复与审批决策

![Claude Ship 官方介绍页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://claude.com/resources/articles/introducing-claude-ship)

*图片来源：[Anthropic / Claude 官方文章](https://claude.com/resources/articles/introducing-claude-ship)*

Anthropic 发布 Claude Ship，由已正式可用的 Code Review，以及 Beta 阶段的 PR Steward 和 Claude Approvals 组成，用于贯穿拉取请求的审查、修复和审批建议。PR Steward 会处理失败检查、合并冲突与审阅意见，并解释所作修改及回滚方式；Claude Approvals 则按照团队预先定义的规则作出审批判断。官方同时强调，该系统用于辅助开发者，不会自行合并代码，而且 AI 仍可能遗漏缺陷或安全问题。

**为什么值得关注：** AI 编程工具正在从“产出代码”进入团队交付控制面；审查、修复、政策化审批与可逆变更被串成同一条工作流，会直接改变代码所有权与人工把关的位置。

- **原文：** [Introducing Claude Ship](https://claude.com/resources/articles/introducing-claude-ship)
- **交叉核验：** [Reuters 报道](https://www.reuters.com/business/anthropic-launches-claude-ship-help-developers-ship-code-faster-2026-11-23/)
- **发布日期：** 2026-11-23
- **时效：** 过去 24 小时

## 2. Codex CLI 0.172.0：强化多智能体导航、逐工具审批与跨平台恢复

![Codex CLI 0.172.0 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openai/codex/releases/tag/rust-v0.172.0)

*图片来源：[OpenAI Codex 官方 GitHub Release](https://github.com/openai/codex/releases/tag/rust-v0.172.0)*

OpenAI 发布 Codex CLI 0.172.0，终端现在可从搜索结果和转录中的线程链接直接打开已保存对话与嵌套智能体，并可在 Agent Command Center 中快速切换任务组。版本新增对单个连接应用工具指定审批审查器的能力，带缓存工具列表的可选 stdio MCP Server 默认延迟到首次调用时启动，同时支持在登录阶段选择 Amazon Bedrock Runtime。恢复逻辑也得到加固：`codex exec resume` 会恢复沙箱权限、工作目录和工作区根目录，父任务被中断时仍保留子智能体排队结果。

**为什么值得关注：** 这批更新把多智能体可见性、细粒度审批和会话恢复同时推进，说明 Codex 正从单任务 CLI 向可治理的并行智能体工作台演进。

- **原文：** [Codex CLI 0.172.0 Release](https://github.com/openai/codex/releases/tag/rust-v0.172.0)
- **发布日期：** 2026-11-24 08:03（新加坡时间）
- **时效：** 过去 24 小时

## 3. DeepMind 用智能体团队与 Lean 形式化验证优化量子算法

![DeepMind 多智能体量子算法研究](https://image.thum.io/get/width/1200/crop/675/noanimate/https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/)

*图片来源：[Google DeepMind 官方研究文章](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/)*

Google DeepMind 与 Google Quantum AI 让多个独立的 Gemini 4 智能体团队寻找量子算法改进，再用 Lean 证明每个结果，团队每四小时通过虚拟会议交换方案。官方报告称，该方法将一项惯性约束聚变计算成本降低 11.8 倍、某光敏分子模拟成本降低 8 倍，并为特定 Grover 算法实现带来 2.57 倍加速。团队已开源 Lean 量子算法库、问题规格和通过验证的解法，但也指出这些算法距离早期容错量子硬件可实际运行仍有资源差距。

**为什么值得关注：** 这是“多智能体协作 + 机器可验证证明”产生真实科学优化的代表性案例；它为自主研发建立了一条比自然语言自我评审更可靠的验收路径。

- **原文：** [Finding faster quantum algorithms with agents and formal verification](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/)
- **发布日期：** 2026-11-23
- **时效：** 过去 24 小时

## 4. OpenCode 2.4.0：内置持久浏览器与事件驱动自动化

![OpenCode 2.4.0 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anomalyco/opencode/releases/tag/v2.4.0)

*图片来源：[OpenCode 官方 GitHub Release](https://github.com/anomalyco/opencode/releases/tag/v2.4.0)*

OpenCode 2.4.0 加入内置桌面浏览器，可导入主流浏览器的登录状态、历史记录与扩展，并在持久配置文件中保留标签页，让智能体直接读取和操作同一浏览环境。新自动化系统可按一次性、间隔、Cron 或 MCP 事件触发提示、Code Mode 脚本与固定 Shell 命令；Shell 动作在创建时审批一次，之后记录每次运行的退出码与输出。版本还支持 MCP Events Beta、插件自动更新回滚，以及后台视频生成，同时带来工具重命名和插件 SDK 兼容性注意事项。

**为什么值得关注：** 浏览器身份、事件触发与持久自动化结合后，编码智能体开始具备跨应用、长期驻留的执行能力；相应的权限规则和插件供应链风险也同步上升。

- **原文：** [OpenCode v2.4.0 Release](https://github.com/anomalyco/opencode/releases/tag/v2.4.0)
- **发布日期：** 2026-11-23 17:22（新加坡时间）
- **时效：** **扩展至过去 72 小时**

## 5. Qwen Code 0.28.4：Web Shell 增加工件库，托管智能体强化恢复与隔离

![Qwen Code 0.28.4 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/QwenLM/qwen-code/releases/tag/v0.28.4)

*图片来源：[Qwen Code 官方 GitHub Release](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.4)*

Qwen Code 0.28.4 为本地守护进程模式的 Web Shell 加入工作区工件库，以渐进扫描和流式更新展示智能体产物，并为中断会话增加 Continue 标记与统一聊天界面。托管智能体运行时修复了延迟构建客户端的竞态，进程启动时即以仅所有者可访问的权限创建状态目录，同时加强工具输出恢复、超大转录索引隔离和 ACP 通道存活判断。版本还内置 Gemini 4 推理默认值，并在 Autofix 失败证据中剥离终端控制字符与 Unicode 双向覆盖符。

**为什么值得关注：** 当自主任务跨越多个会话和工件时，产物发现、状态恢复、租户隔离与日志净化构成同一条可靠性边界；该版本对这些基础环节进行了系统性补强。

- **原文：** [Qwen Code v0.28.4 Release](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.4)
- **发布日期：** 2026-11-22 20:04（新加坡时间）
