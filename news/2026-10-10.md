- **事实摘要：**OpenAI 发布 Codex CLI 0.162.1，修复 TUI 在异步问题包含多行文本时崩溃的问题，并保留换行与完整超链接目标。版本还修复后台服务器与 CLI 默认 feature 设置不一致时的启动失败：兼容性检查现仅针对用户在命令行中明确覆盖的 feature。该版本是 0.162.0 后的快速补丁，聚焦交互可靠性而非新增大功能。

## 2. Claude Code 2.1.296：托管策略改为真正“拒绝并终止”，并加固文件与命令边界

![Claude Code 2.1.296 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.296)

*图片来源：[Anthropic Claude Code 官方 GitHub 发布页](https://github.com/anthropics/claude-code/releases/tag/v2.1.296)*

- **时间范围：**过去 24 小时
- **发布日期：**2026-10-10（新加坡时间；GitHub 发布时间为 2026-10-09 19:28 UTC）
- **事实摘要：**Claude Code 2.1.296 修复托管设置中的 `PreToolUse` 与 prompt hooks：当策略返回阻断时，现在会拒绝调用并结束当前回合，而不只是拒绝后继续运行。版本同时堵住 `BASH_ARGV0` 相关命令的自动批准路径，并让 Edit/NotebookEdit 在遇到 Windows-1252、Shift-JIS、GBK 等非 UTF-8 文件时直接拒绝，避免把非 ASCII 字符破坏。新增的 `autoCompactWindow` 可让子智能体早于主会话压缩上下文，`CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` 则允许工作流子智能体统一选模。
- **为什么值得关注：**这次更新把“策略拒绝”从提示层语义落实到回合控制，同时兼顾长程上下文与子智能体模型治理；它直指企业使用编码智能体时最容易出事故的授权、编码和持续运行边界。
- **原文链接：**[Claude Code 2.1.296](https://github.com/anthropics/claude-code/releases/tag/v2.1.296) · [官方 CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

## 3. Codex 输入框加入 Composer Predictions：模型预测下一条指令，但不自动发送

![OpenAI ChatGPT/Codex 发布说明](https://image.thum.io/get/width/1200/crop/675/noanimate/https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

*图片来源：[OpenAI 官方发布说明](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)*

- **时间范围：**扩展至过去 72 小时（官方仅标注 2026-10-09）
- **发布日期：**2026-10-09
- **事实摘要：**OpenAI 在 Codex 桌面端测试 Composer Predictions：系统会根据当前线程预测用户可能发送的下一条消息，并把建议显示在输入框中。用户按 Tab 接受后仍可编辑，系统不会自动发送；测试面向受支持地区的 18 岁以上个人 ChatGPT Pro 用户，并适用于使用 GPT-6 Astra 或 GPT-6.1 Sol 的本地与 SSH 线程。预测生成在 beta 期间不计费，但实际发送的消息仍按正常额度或计费规则处理。
- **为什么值得关注：**编码智能体正从“回答指令”走向主动建议下一步，但 OpenAI 保留了明确的人类确认点；这是一种在提高任务连续性的同时，避免代理自行扩大工作范围的交互设计。
- **原文链接：**[OpenAI ChatGPT/Codex 发布说明](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

*图片来源：[Anthropic Claude Platform 官方文档](https://platform.claude.com/docs/en/release-notes/overview)*

- **时间范围：**扩展至过去 72 小时（官方仅标注 2026-10-09）
- **发布日期：**2026-10-09
- **事实摘要：**Anthropic 为 Claude Managed Agents 推出动态工作流 beta；面对数百份文档等多分片任务，主智能体可以自行编写工作流程序，按阶段运行多个智能体并汇总结果。工作流由服务器在后台执行，开发者可通过 session event stream 中的 `workflow_run.*` 事件跟踪。功能需使用 `managed-agents-2026-04-01` beta header，并在 agent 的 `multiagent` 配置中显式开启 workflows。
