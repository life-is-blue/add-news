## 1. GitHub 发布 ReviewBench：把 AI 代码审查拉回真实 PR 分布

![GitHub ReviewBench 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.blog/ai-and-ml/github-copilot/reviewbench-an-open-benchmark-for-ai-code-review/)

*图片来源：[GitHub 官方博客](https://github.blog/ai-and-ml/github-copilot/reviewbench-an-open-benchmark-for-ai-code-review/)*

- **时间范围：**过去 24 小时
- **发布日期：**2026-10-05
- **事实摘要：**GitHub 开源发布 ReviewBench：基于 1.039 亿个真实 GitHub PR 的分布构建，语料含 187 个开源仓库的 219 个 PR、覆盖 19 种语言，并综合人类审查、后续修复提交、静态分析与多个前沿模型形成黄金集。独立资深工程师复标的一致率为 96.6%；该基准同时报告 grounded 与 augmented 的 precision、recall 和 F1，以便给黄金集之外的新发现计分。GitHub 称其在一项 Copilot Code Review 线上实验中正确预判了指标方向，但线上实验仍是最终用户效果标准。
- **为什么值得关注：**代码审查智能体终于有了更贴近生产分布、可复现且能区分严重度与噪声偏好的公共评测；这比只看漏洞命中数更有助于团队比较不同审查代理的真实取舍。
- **原文链接：**[GitHub 官方博客](https://github.blog/ai-and-ml/github-copilot/reviewbench-an-open-benchmark-for-ai-code-review/)｜[ReviewBench](https://review-bench.ai/)

## 2. Claude Code 2.1.290 强化多智能体权限观测，2.1.291 紧急修回归

![Claude Code 2.1.291 发布页面](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.291)

*图片来源：[Anthropic Claude Code 官方 GitHub 发布页](https://github.com/anthropics/claude-code/releases/tag/v2.1.291)*

- **时间范围：**过去 24 小时
- **发布日期：**2026-10-06（2.1.290 发布于 2026-10-05）
- **事实摘要：**Anthropic 在 2.1.290 为插件权限钩子加入 `agentId` 与组织要求的 approval `ceiling`，使扩展能够区分主会话和子智能体的授权检查，并新增 gating hook 的 `.catch` 校验；同时修复托管 MCP、计划任务、长会话、符号链接读取和多处 sandbox/权限边界问题。数小时后的 2.1.291 修复 2.1.290 导致云会话丢失权限提示回答的回归，以及 2.1.288 起退出时可能丢失会话末尾消息的问题。
- **为什么值得关注：**多智能体系统的权限判断必须能追溯到具体代理并服从组织上限；紧随大版本而来的热修也说明无人值守会话需要把升级回滚、提示应答与会话持久化纳入回归测试。
- **原文链接：**[v2.1.290](https://github.com/anthropics/claude-code/releases/tag/v2.1.290)｜[v2.1.291](https://github.com/anthropics/claude-code/releases/tag/v2.1.291)

## 3. Codex 0.160.1 修复跨 Unix/Windows 的远程 MCP 启动环境

![OpenAI Codex 0.160.1 发布页面](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openai/codex/releases/tag/rust-v0.160.1)

*图片来源：[OpenAI Codex 官方 GitHub 发布页](https://github.com/openai/codex/releases/tag/rust-v0.160.1)*

- **时间范围：**过去 24 小时
- **发布日期：**2026-10-05
- **事实摘要：**OpenAI 发布 Codex 0.160.1，回移一项远程 MCP 修复：当 Unix 主机以显式远程环境变量启动 Windows 执行器上的 stdio MCP 服务器时，保留 `SYSTEMROOT`、`TEMP` 和 `TMP`。此前这些启动环境可能被覆盖，导致依赖 Windows 系统目录或临时目录的远程工具无法正常拉起。
- **为什么值得关注：**自主开发越来越依赖跨主机、跨操作系统的 MCP 工具；这一小型稳定版修复直接命中远程执行最常见却难排查的环境继承故障。
- **原文链接：**[Codex 0.160.1 Release](https://github.com/openai/codex/releases/tag/rust-v0.160.1)｜[修复 PR #51121](https://github.com/openai/codex/pull/51121)

## 4. GitHub 密钥扫描覆盖 Lovable、Pydantic AI 与 Supabase 凭据

![GitHub 密钥扫描新增检测器公告](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.blog/changelog/2026-10-05-secret-scanning-adds-detectors-for-lovable-supabase-and-more/)

*图片来源：[GitHub 官方更新页面](https://github.blog/changelog/2026-10-05-secret-scanning-adds-detectors-for-lovable-supabase-and-more/)*

- **时间范围：**过去 24 小时
- **发布日期：**2026-10-05
- **事实摘要：**GitHub Secret Scanning 新增对 `lovable_api_key`、`logfire_token`、`pydantic_ai_gateway_api_key`、`supabase_oauth_access_token` 与 `supabase_scoped_personal_access_token` 的检测。Lovable 同时加入 secret scanning 合作伙伴计划：公开仓库发现其密钥时，GitHub 会把事件转交发行方，以便在被滥用前撤销或轮换；用户型密钥则在公开或私有仓库触发警报。
- **为什么值得关注：**AI 生成应用常把 Lovable、Pydantic AI 与 Supabase 串在同一开发链路中；扫描器同步覆盖这些凭据，可以降低智能体误写配置或提交环境变量造成的供应链暴露。
- **原文链接：**[GitHub Changelog](https://github.blog/changelog/2026-10-05-secret-scanning-adds-detectors-for-lovable-supabase-and-more/)

## 5. Reflection 发布 Beam：面向编码与智能体任务的 501B 开放权重 MoE

![Reflection Beam 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://reflection.ai/blog/introducing-beam)

*图片来源：[Reflection 官方发布页](https://reflection.ai/blog/introducing-beam)*

- **时间范围：**过去 24 小时
- **发布日期：**2026-10-05
- **事实摘要：**Reflection 宣布 Beam，这是一款面向编码、推理与智能体工作负载的稀疏 MoE 模型，含 5010 亿总参数、每个 token 激活 230 亿参数；官方称其预训练使用 23.8 万亿 token，并在 10,500 张 NVIDIA GB300 上进行四周、超过 1 亿次 rollout 的强化学习。路透确认了发布与核心规模数据；不过模型仍在最终红队与评测阶段，完整权重、技术报告、模型卡和安全结果计划本月发布，因此当前性能比较主要是厂商主张，尚不能视为独立验证。
- **为什么值得关注：**如果后续权重与复现实验支持其效率声明，Beam 可能为私有部署的编码智能体提供新的高容量开放模型选项；更关键的是，完整报告和安全材料是否兑现，将检验“开放权重 + 前沿智能体能力”的发布治理。
- **原文链接：**[Reflection 官方公告](https://reflection.ai/blog/introducing-beam)｜[Reuters 交叉核验](https://www.reuters.com/technology/nvidia-backed-reflection-unveils-first-ai-model-take-chinese-open-models-2026-10-05/)
