## 1. Codex CLI 0.167.0 上线无守护进程智能体指挥中心

![Codex CLI 0.167.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openai/codex/releases/tag/rust-v0.167.0)

*图片来源：[OpenAI Codex 官方 GitHub 发布页](https://github.com/openai/codex/releases/tag/rust-v0.167.0)*

Codex CLI 0.167.0 新增 `codex agents --no-daemon`，可直接打开智能体指挥中心，并在指挥中心和会话选择器中标记未读结果。终端会话选择器现在可在已连接后端之间切换且保留草稿；支持的终端还可预览本地图片附件，并从对话记录中的可点击路径打开图片。登录流程新增 API Key、云提供商入口和可选的 Google Cloud Vertex AI 配置向导，同时补充了托管网络约束与需要重新取得人工批准的命令规则文档。

**为什么值得关注：** 这次更新把 Codex 的终端体验从单会话助手进一步推向多智能体控制台，并开始统一不同推理后端、图片上下文和云身份配置；对需要同时监督多条编码任务的开发者而言，未读状态、草稿保留和明确审批边界都是生产可用性的关键细节。

- **原文：** [Codex CLI 0.167.0 Release](https://github.com/openai/codex/releases/tag/rust-v0.167.0)
- **发布日期：** 2026-11-06
- **时间范围：** 过去 24 小时

## 2. GitHub Copilot CLI 1.0.106 打通 VS Code 与本地多会话协作

![GitHub Copilot CLI 1.0.106 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/github/copilot-cli/releases/tag/v1.0.106)

*图片来源：[GitHub Copilot CLI 官方发布页](https://github.com/github/copilot-cli/releases/tag/v1.0.106)*

GitHub Copilot CLI 1.0.106 新增 `/code`，可把当前会话直接在 VS Code 中打开；同时加入可选的本地会话管理工具与会话 @mention，以及供 LSP 和本地 MCP 服务器解析工作目录的 `COPILOT_SESSION_CWD`。新版本还提供统一设置面板和全局搜索、扩展进程沙箱设置、支持终端的程序状态提示，并允许符合条件的账号选择 GPT‑6.1 Terra。可靠性方面，它修复了切换繁忙会话导致终端崩溃、沙箱内相对路径 MCP 启动失败，以及 Autopilot 在仅被要求审查或分析时擅自实施建议等问题。

**为什么值得关注：** “终端智能体—IDE—LSP/MCP—并行会话”正在形成一条连续工作链；尤其是抑制 Autopilot 越权执行与把扩展放入沙箱，说明自主开发产品的竞争焦点正从生成能力转向会话编排和可控执行。

- **原文：** [GitHub Copilot CLI 1.0.106 Release](https://github.com/github/copilot-cli/releases/tag/v1.0.106)
- **发布日期：** 2026-11-06
- **时间范围：** 过去 24 小时

## 3. GPT‑6‑Cyber 进入 API，面向授权漏洞复现与修复验证

![GPT-6-Cyber 官方模型文档](https://image.thum.io/get/width/1200/crop/675/noanimate/https://developers.openai.com/api/docs/models/gpt-6-cyber)

*图片来源：[OpenAI GPT‑6‑Cyber 官方模型文档](https://developers.openai.com/api/docs/models/gpt-6-cyber)*

OpenAI 在 11 月 5 日的 API 更新中发布 GPT‑6‑Cyber，用于调查漏洞、在授权测试环境中复现问题并验证修复；使用者需要获得 Daybreak Red 单独审批。OpenAI 的安全文档将该模型的网络安全能力评为“Critical”，因此通过专门访问计划、请求分类与受控环境限制高风险用途。作为相邻证据，OpenAI 11 月 4 日披露的一套自主流水线在隔离环境中扫描 Linux 内核，动态复现 1,724 个漏洞，并为 948 个本地提权问题生成可工作的利用验证和候选补丁；官方未明确表示该实验中的“即将发布的网络安全模型”就是 GPT‑6‑Cyber。

**为什么值得关注：** 高能力模型已经从发现代码缺陷跨入“复现—评估可利用性—生成补丁—人工审查”的完整闭环；这既可能显著压缩防御周期，也迫使团队把授权、隔离、披露和补丁验收纳入智能体系统的基础架构。

- **原文：** [OpenAI API Changelog](https://developers.openai.com/api/docs/changelog) · [GPT‑6‑Cyber Model](https://developers.openai.com/api/docs/models/gpt-6-cyber)
- **交叉核验：** [A thousand fewer paths to root](https://openai.com/index/a-thousand-fewer-paths-to-root/)
- **发布日期：** 2026-11-05
- **时间范围：** 扩展至过去 72 小时

## 4. Gemini CLI 0.67.0 强化模型发现、沙箱取消与 ACP 权限上下文

![Gemini CLI 0.67.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/google-gemini/gemini-cli/releases/tag/v0.67.0)

*图片来源：[Google Gemini CLI 官方 GitHub 发布页](https://github.com/google-gemini/gemini-cli/releases/tag/v0.67.0)*

Gemini CLI 0.67.0 新增 `models` 命令与 `--list-models`，让脚本和用户可直接发现可用模型；IDE companion 也能通过 exec stdio 桥接到容器沙箱。该版本修复非交互模式取消后仍继续执行工具、外部输出的不受信任参数检查范围、原子写入只读文件或硬链接，以及工作区相对路径解析等问题。ACP 权限请求现在会包含 MCP 服务器与工具元数据，A2A 服务器则保留更完整的令牌用量信息。

**为什么值得关注：** 模型可发现性、取消语义、文件写入边界和工具来源信息决定了编码智能体能否被安全地嵌入 CI、IDE 与其他智能体协议；这些底层修复比单次基准提升更直接影响自动化流水线的可预测性。

- **原文：** [Gemini CLI v0.67.0 Release](https://github.com/google-gemini/gemini-cli/releases/tag/v0.67.0)
- **发布日期：** 2026-11-04
- **时间范围：** 扩展至过去 72 小时

## 5. Claude Code 2.1.318 修复会话丢失、权限误触与并发配置写入

![Claude Code 2.1.318 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.318)

*图片来源：[Anthropic Claude Code 官方 GitHub 发布页](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)*

Claude Code 2.1.318 为 mod 的模型分叉加入独立 `effort` 设置，使旁路任务可用较低推理强度运行；认证状态现在会公开登录到期时间，并在到期前 10 天向无头输出发出警告。版本修复了畸形工具调用重试耗尽后 `--continue` 丢失早期对话、macOS 多 Bash 任务导致内存增长和停滞，以及缓慢出现的权限提示被预先键入按键误答。MCP 配置增删开始等待文件锁或明确失败，多个登出、信任与插件命令也不再在配置无法保存时虚报成功。

**为什么值得关注：** 长程编码会话最危险的失败不是明显报错，而是上下文、权限或配置在并发与恢复时悄悄漂移；这批修复把会话连续性、权限确认和配置原子性提升为一等工程问题，也为无头运行和团队环境降低了隐性风险。

- **原文：** [Claude Code v2.1.318 Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)
- **发布日期：** 2026-11-04
- **时间范围：** 扩展至过去 72 小时
