## 1. Codex 0.161.0：GPT-6.1 Sol 成为默认模型，MCP 登录与权限继承同步加强

![Codex 0.161.0 发布页面](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openai/codex/releases/tag/rust-v0.161.0)

*图片来源：[OpenAI Codex 官方 GitHub 发布页](https://github.com/openai/codex/releases/tag/rust-v0.161.0)*

- **时间范围：**过去 24 小时
- **发布日期：**2026-10-07
- **事实摘要：**OpenAI 在 Codex 0.161.0 中把 GPT-6.1 Sol 设为内置目录与 Amazon Bedrock 目录的默认模型，并为 Bedrock 增加多智能体 V2、Ultra 推理强度及 AWS GovCloud 区域支持。CLI 新增 `/mcp login <name>`，可直接为当前会话中的 MCP 服务器完成登录；Daybreak 与 Cyber Access Program 则改为显式按参数启用。版本还修复提权后的文件系统范围丢失原有拒绝规则，以及后台任务未保留发起回合权限等边界问题。
- **为什么值得关注：**这次更新把模型路由、MCP 身份验证和任务权限继承放进同一个运行时版本，说明编码智能体的竞争重点正从“会不会写代码”转向“能否在多云、长任务和最小权限条件下稳定执行”。
- **原文链接：**[OpenAI Codex 0.161.0](https://github.com/openai/codex/releases/tag/rust-v0.161.0)

![Claude Code 2.1.294 发布页面](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.294)

- **时间范围：**过去 24 小时
- **发布日期：**2026-10-08（2.1.293 发布于 2026-10-07）
- **事实摘要：**2.1.293 将 Claude Haiku 5.5 接入 Claude Code，并把它设为 Anthropic API 上的默认 Haiku 模型，同时修复压缩后重复或撤回工作、HTTP MCP 请求内存泄漏、后台化时队列消息丢失及多项守护进程和会话恢复问题。数小时后的 2.1.294 专门修复 prompt/agent hooks 被写成“指令”而非真正阻断条件的问题，并改进 Stop 与 SubagentStop 钩子的判断，避免智能体过早结束。

- **原文链接：**[Claude Code 2.1.293](https://github.com/anthropics/claude-code/releases/tag/v2.1.293) · [Claude Code 2.1.294](https://github.com/anthropics/claude-code/releases/tag/v2.1.294)

## 4. GitHub Copilot 本地沙箱正式可用：用原生系统控制隔离代理工具

![GitHub Copilot 本地沙箱正式发布](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available/)

*图片来源：[GitHub 官方更新页面](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available/)*

- **时间范围：**过去 24 小时
- **发布日期：**2026-10-07
- **事实摘要：**GitHub 宣布 Copilot CLI、Copilot app 与使用 Agent Host 的 VS Code 会话均已正式支持本地沙箱。该能力由 Microsoft eXecution Container（MXC）提供，把统一策略转换为 Windows、macOS 和 Linux 的原生控制，可限制文件、目录、互联网、本地网络、Git 凭据与 GitHub CLI 凭据，并可覆盖本地 MCP 与语言服务器。企业管理员还能强制启用沙箱并阻止开发者削弱策略，且功能不额外收费。
- **为什么值得关注：**模型安全与工具隔离是两件不同的事；把代理命令约束下沉到操作系统，并允许组织集中强制策略，是本地编码智能体从个人工具走向企业部署的重要门槛。
- **原文链接：**[GitHub Changelog](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available/)

## 5. GitLab 推出“受治理的软件工厂”，把智能体交付纳入统一证据链

![GitLab 受治理的软件工厂公告](https://image.thum.io/get/width/1200/crop/675/noanimate/https://about.gitlab.com/press/releases/2026-10-06-gitlab-announces-the-foundation-for-the-governed-software-factory/)

*图片来源：[GitLab 官方公告](https://about.gitlab.com/press/releases/2026-10-06-gitlab-announces-the-foundation-for-the-governed-software-factory/)*

- **时间范围：**扩展至过去 72 小时
- **发布日期：**2026-10-06
- **事实摘要：**GitLab 发布“受治理的软件工厂”能力组合，以统一身份、策略和证据链连接需求、编码、审查、测试、安全与部署；`/goal`、Custom Flows 和 Flow Triggers 可让多步智能体工作在 Duo CLI、Agentic Chat 与 Slack 中连续推进。Dependency Firewall、Secrets Manager 和 GitLab Security Standard 用于在构建前阻断恶意或不合规依赖并管理凭据，Impact Analytics 则按团队、任务和模型展示 AI 成本与产出。GitLab 还宣布 Orbit 将于下月全面可用，但其“最多减少 45 倍重试、4.5 倍 token”的数据属于厂商自报。
- **为什么值得关注：**企业采用自主开发智能体的瓶颈正从代码生成转向跨阶段治理：谁触发、用什么身份、经过哪些门禁、花了多少成本、如何还原决策链，正在成为平台级竞争核心。
- **原文链接：**[GitLab 官方公告](https://about.gitlab.com/press/releases/2026-10-06-gitlab-announces-the-foundation-for-the-governed-software-factory/)
