## 1. Codex CLI 0.170.0：TUI 接入实时语音，MCP 与云会话恢复更稳

![Codex CLI 0.170.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openai/codex/releases/tag/rust-v0.170.0)

*配图来源：[OpenAI Codex 官方 GitHub Release](https://github.com/openai/codex/releases/tag/rust-v0.170.0)*

OpenAI 为 Codex CLI 加入 TUI 实时语音通话的 WebRTC 协商，并让 OpenTelemetry HTTP exporter 的认证头能够自动刷新。该版还试验性支持在不同环境中使用同名 MCP 服务器，同时修复大体积 WebSocket 请求回退、MCP OAuth 凭据竞态、云会话重连以及 Windows 沙箱权限保留等问题。

**为什么值得关注：** Codex 正把交互入口从纯文本终端扩展到实时语音；与此同时，MCP 身份隔离、会话恢复和沙箱约束的修复，直接决定长时间自主开发任务能否安全、连续地运行。

- **原文：** [Codex CLI 0.170.0 Release Notes](https://github.com/openai/codex/releases/tag/rust-v0.170.0)
- **发布日期：** 2026-11-18（新加坡时间）

![Claude Code 2.1.327 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.327)

*配图来源：[Anthropic Claude Code 官方 GitHub Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.327)*

Anthropic 在 `/install-github-app` 修改仓库前增加确认，并允许 `claude mcp add-json <name> -` 从标准输入读取配置，避免令牌出现在命令行参数中；`/status` 也会集中列出损坏的 agent、skill、command、沙箱与权限配置。更新同时修复 Remote Control 工作树模式误删 `.env` 等 git-ignore 文件、项目级 MCP 修改破坏 `.mcp.json` 其他键，以及崩溃、压缩或重启后丢失消息、任务和子智能体状态等问题。

## 4. Qwen Code 0.28.0：统一智能体循环，推进跨工作区协作

![Qwen Code 0.28.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/QwenLM/qwen-code/releases/tag/v0.28.0)

*配图来源：[QwenLM Qwen Code 官方 GitHub Release](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.0)*

Qwen Code 0.28.0 默认让无头会话、Ink TUI 和子智能体运行在共享 agent loop 上，并新增外部工作区执行、跨工作区子会话、Codex 风格托管 worktree 会话与会话间消息能力。更新还加入 qwen4-max 原生 effort 档位，强化压缩后操作保留、工作区准备、PR 验证边界和 TOCTOU 防护，并修复中断后历史与 shell 输出丢失等可靠性问题。

**为什么值得关注：** 共享执行循环和跨工作区会话把 CLI、托管智能体与子智能体从分散实现拉到同一编排层，为多智能体并行开发、工作树隔离及可恢复协作提供更一致的基础。

- **原文：** [Qwen Code 0.28.0 Release Notes](https://github.com/QwenLM/qwen-code/releases/tag/v0.28.0)

## 5. Goose 1.60.1：修复 Claude 压缩后拒绝继续的问题

![Goose 1.60.1 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/aaif-goose/goose/releases/tag/v1.60.1)

*配图来源：[AAIF Goose 官方 GitHub Release](https://github.com/aaif-goose/goose/releases/tag/v1.60.1)*

Goose 1.60.1 修复了一项模型兼容性故障：在上下文压缩时丢弃 Claude 模型会拒绝接受的 `<analysis>` 草稿内容。该维护版本的变更范围很小，但直指长会话压缩后无法继续执行的阻断性问题。

**为什么值得关注：** 自主编码会话越长，压缩与模型协议兼容越容易成为隐藏单点故障；这项修复说明智能体框架不仅要管理 token，还必须清理模型私有或不被接受的中间表示，才能保持跨模型运行连续性。

- **原文：** [Goose 1.60.1 Release Notes](https://github.com/aaif-goose/goose/releases/tag/v1.60.1)
- **发布日期：** 2026-11-18（新加坡时间）
