## 5. GitHub App 全面切换无状态安装令牌，智能体集成需检查长度假设

![GitHub App 无状态安装令牌公告](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.blog/changelog/2026-10-02-stateless-github-app-installation-tokens-rolled-out/)

*图片来源：[GitHub 官方更新页面](https://github.blog/changelog/2026-10-02-stateless-github-app-installation-tokens-rolled-out/)*

- **时间范围：**过去 72 小时（扩展）
- **发布日期：**2026-10-02
- **事实摘要：**GitHub 宣布无状态 GitHub App 安装令牌的分阶段部署已完成，新签发令牌默认使用 `ghs_APPID_JWT` 格式，长度由约 40 字符增至约 520 字符；权限、仓库范围、一小时有效期及 REST 端点保持不变。用于强制选择旧/新格式的临时 `X-GitHub-Stateless-S2S-Token` 请求头将在 2026-11-30 停用，GitHub 要求集成方检查固定长度字段、旧正则、代理头限制和脱敏规则。
- **为什么值得关注：**大量代码智能体通过 GitHub App 获取仓库权限；若令牌存储、网关或日志脱敏仍假设 40 字符，可能导致认证中断或秘密泄漏，因此这是需要立即纳入智能体基础设施回归测试的兼容性变化。
- **原文链接：**[GitHub Changelog](https://github.blog/changelog/2026-10-02-stateless-github-app-installation-tokens-rolled-out/)
