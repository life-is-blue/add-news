## 1. Codex CLI 0.153.4 修正 Astra 可见性与默认模型选择

![Codex CLI 0.153.4 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openai/codex/releases/tag/rust-v0.153.4)

*图片来源：[OpenAI Codex 官方 GitHub 发布页](https://github.com/openai/codex/releases/tag/rust-v0.153.4)*

OpenAI 于 9 月 4 日 23:25 UTC 发布 Codex CLI 0.153.4，修复 Astra 在内置模型选择器中的可见性，并在用户未显式配置模型时将其设为默认。版本还调整了 Astra 的使用指引：只有在异步提问工具可用时，才建议模型采用异步提问。此次改动属于紧随模型迁移后的兼容性修复，重点是让模型发现与默认路由保持一致。

**为什么值得关注：** 编码智能体的实际体验不只取决于模型能力，模型目录、默认路由和工具能力提示同样会直接影响任务能否稳定启动；这次小版本修复暴露了“模型发布—CLI 分发—工具协议”需要同步演进。

- **原文：** [Codex CLI 0.153.4 Release](https://github.com/openai/codex/releases/tag/rust-v0.153.4)
- **发布日期：** 2026-09-04（过去 24 小时）

## 2. Claude Code 2.1.261 加强技能诊断、子智能体定制与会话完整性

![Claude Code 更新日志](https://image.thum.io/get/width/1200/crop/675/noanimate/https://code.claude.com/docs/en/changelog)

*图片来源：[Anthropic Claude Code 官方更新日志](https://code.claude.com/docs/en/changelog)*

Claude Code 2.1.261 新增 `/skill-doctor`，可识别未使用技能并显示技能的上下文成本，同时加入 `--append-subagent-system-prompt-file`，让团队能在不替换默认提示的情况下扩展子智能体行为。该版本把 Bash 与任务输出上限提高到 128K，并修复恢复会话时丢失 Hook 输出、并行工具调用上下文，以及后台智能体重试导致高 CPU 等问题。危险 `rm` 命令的确认拦截也覆盖了更多变体。

**为什么值得关注：** 这组更新把关注点从“能调用智能体”推进到“能观察、约束并恢复智能体”，尤其是技能上下文成本和恢复会话完整性，都是长期自主开发流程中的关键工程指标。

- **原文：** [Claude Code Changelog](https://code.claude.com/docs/en/changelog)
- **发布日期：** 2026-09-04（过去 24 小时）

## 5. 【扩展至 72 小时】判别式世界模型提升网页智能体动作选择

![Discriminative World Models for Web Agents 论文页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://arxiv.org/abs/2609.02885)

*图片来源：[arXiv 论文页面](https://arxiv.org/abs/2609.02885)*

研究团队提出 predicted-state matching：世界模型不仅预测执行动作后的网页状态，还必须区分真实结果与其他候选动作产生的状态。模型使用由 WebArena Go-Browse 轨迹构建的分支数据集训练，在作者报告的实验中，相比监督式下一状态预测改善了 WebPRMBench 的动作排序，并提高 WebArena-Lite 的端到端任务成功率。论文目前为 arXiv 预印本，结论仍待更广泛复现。

**为什么值得关注：** 网页智能体的瓶颈正从“能否生成动作”转向“能否在多个可行动作中可靠预判后果”；将世界模型训练目标直接对齐动作排序，为降低长链任务中的错误累积提供了可检验路径。

- **原文：** [Discriminative World Models for Web Agents](https://arxiv.org/abs/2609.02885)
- **发布日期：** 2026-09-02（扩展至过去 72 小时）
