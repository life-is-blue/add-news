## 1. Claude Code 2.1.322 将 Fast Mode 扩展至 Vertex AI 多区域

![Claude Code 2.1.322 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.322)

*图片来源：[Anthropic Claude Code 官方 GitHub 发布页](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)*

Claude Code 2.1.322 为 Google Cloud Vertex AI 的全球、美国和欧盟区域加入 Fast Mode。若 Vertex 拒绝快速通道，请求会自动回退至标准速度，而不是直接让当前任务失败。该版本由 Claude Code 官方发布账号签名并标记为最新稳定版。

**为什么值得关注：** 企业常通过 Vertex AI 托管 Claude Code；区域覆盖与自动降级让低延迟模式能够进入生产工作流，同时避免容量或策略拒绝演变为智能体任务中断。

- **原文：** [Claude Code v2.1.322 Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)
- **发布日期：** 2026-11-10
- **时间范围：** 过去 24 小时

## 2. OpenHands 1.38.0 让自动化继承智能体配置并改进可移植性

![OpenHands 1.38.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/OpenHands/OpenHands/releases/tag/v1.38.0)

*图片来源：[OpenHands 官方 GitHub 发布页](https://github.com/OpenHands/OpenHands/releases/tag/v1.38.0)*

OpenHands 1.38.0 允许提示词与插件预设从 Agent Profile 运行，并加入面向自动化的安装模式及插件规范接口。自动化导入导出现在会携带脚本包，帮助团队在环境间迁移完整任务；版本也保留自动化上下文，并允许组织管理员维护其他用户的自动化。Docker 侧新增智能体服务失联时非零退出、不可写挂载快速失败及工作区持久化修复。

**为什么值得关注：** 自动化要进入团队使用，必须把智能体配置、脚本、权限和运行环境作为一个可移植单元；这次更新把 OpenHands 从个人会话工具进一步推向可治理的组织级自动化平台。

- **原文：** [OpenHands v1.38.0 Release](https://github.com/OpenHands/OpenHands/releases/tag/v1.38.0)
- **发布日期：** 2026-11-10
- **时间范围：** 过去 24 小时

## 3. Hermes Agent 0.23.1 修复插件目录超限导致的静默回退

![Hermes Agent 0.23.1 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.1)

*图片来源：[Nous Research Hermes Agent 官方 GitHub 发布页](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.1)*

Hermes Agent 0.23.1 修复在线插件目录超过客户端 2 MiB 上限后，安装命令静默回退到随版本附带旧目录的问题。上限提高到 16 MiB 后，客户端会重新读取实时目录，避免找不到新插件、安装旧固定版本或遗漏已移除条目。该稳定补丁同时汇总 v0.23.0 以来约 618 个合并 PR，并覆盖 CLI、安装器、Microsoft Store、Docker 与 Hermes Cloud。

**为什么值得关注：** 智能体插件目录本质上是能力供应链；静默使用旧索引会让版本固定、撤回和安全处置全部失效，修复后插件解析重新回到可预期、可治理的状态。

- **原文：** [Hermes Agent v0.23.1 Release](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.1)
- **发布日期：** 2026-11-10（发布页内版本日期标为 2026-11-09）
- **时间范围：** 过去 24 小时

## 4. Claude Agent ACP 0.102.0 将工作流阶段、智能体与计划同步到编辑器

![Claude Agent ACP 0.102.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/agentclientprotocol/claude-agent-acp/releases/tag/v0.102.0)

*图片来源：[Agent Client Protocol 官方 GitHub 发布页](https://github.com/agentclientprotocol/claude-agent-acp/releases/tag/v0.102.0)*

Claude Agent ACP 0.102.0 在工作流卡片中展示各阶段与参与智能体，并把检查清单作为 ACP plan 操作发送给客户端，重置时同步移除计划。版本还把没有对应工具调用的 v2 后台任务报告为独立工具调用，使客户端能够正确显示和跟踪它们。依赖同步升级至 Claude Agent SDK 0.3.321。

**为什么值得关注：** 多智能体工作流若只显示最终文本，编辑器很难判断当前阶段、负责人和后台进度；将阶段、成员、清单与后台任务映射为协议级事件，是可观察、可中断协作的基础。

- **原文：** [Claude Agent ACP v0.102.0 Release](https://github.com/agentclientprotocol/claude-agent-acp/releases/tag/v0.102.0)
- **发布日期：** 2026-11-09
- **时间范围：** 过去 24 小时

## 5. GitHub Copilot CLI 1.0.108 强化索引、沙箱路径与 MCP 目录隔离

![GitHub Copilot CLI 1.0.108 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/github/copilot-cli/releases/tag/v1.0.108)

*图片来源：[GitHub Copilot CLI 官方发布页](https://github.com/github/copilot-cli/releases/tag/v1.0.108)*

Copilot CLI 1.0.108 新增 `/index` 命令，并为符合条件的仓库默认启用托管共享 tgrep 索引；Windows 沙箱则加入仅枚举目录的权限配置。开启沙箱后，执行 `/cd` 会重启本地 MCP 服务器，使其继承新目录的拒绝路径，而不是继续沿用旧工作目录边界。版本还拒绝把命名管道、套接字或设备当作普通附件，检测重复自定义工具名，并让 Grok 4.6/4.7 的 PDF 附件失败时回退为文件引用。

**为什么值得关注：** 仓库索引能改善大代码库检索，但目录切换与本地 MCP 若没有同步重建安全边界，会造成权限漂移；这次版本同时推进检索能力和最小权限隔离。

- **原文：** [GitHub Copilot CLI v1.0.108 Release](https://github.com/github/copilot-cli/releases/tag/v1.0.108)
- **发布日期：** 2026-11-09
- **时间范围：** 过去 24 小时
