## 2. Cloudflare 推出 Search for Agents，让网站原生暴露可发现搜索【扩展至 72 小时】

![Cloudflare Search for Agents 官方公告](https://image.thum.io/get/width/1200/crop/675/noanimate/https://blog.cloudflare.com/search-for-agents/)

*图片来源：[Cloudflare 官方博客](https://blog.cloudflare.com/search-for-agents/)（公告页面截图）*

Cloudflare 发布 Search for Agents：站点所有者可用一个开关创建 AI Search 索引，并在自身域名的 `/.well-known/search` 暴露可被智能体自动发现的检索端点。端点支持 GET 与标准化的 HTTP QUERY 方法，返回带来源的 Markdown 检索结果而非预生成答案；官方文档确认该功能以 Beta 形式覆盖所有套餐，并仍受 AI Crawl Control 与 WAF 规则约束。Cloudflare 还用 OpenCode 会话演示了智能体从页面元数据发现端点并调用它查阅开发文档。

**为什么值得关注：** 这把智能体获取文档的入口从专用 MCP、抓取脚本或厂商 API 下沉到域名级约定，有机会形成更低摩擦、可由站点所有者治理的“面向智能体的搜索层”。

- **原文：** [Introducing Search for Agents](https://blog.cloudflare.com/search-for-agents/)
- **交叉核验：** [Cloudflare 开发者文档](https://developers.cloudflare.com/ai-search/how-to/search-for-agents/)
- **发布日期：** 2026-11-25

## 3. Microsoft 披露 Agent Framework PyPI 包被未授权植入窃密代码【扩展至 72 小时】

![Microsoft Agent Framework 安全更新](https://image.thum.io/get/width/1200/crop/675/noanimate/https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-repository-update/)

*图片来源：[Microsoft Agent Framework 官方博客](https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-repository-update/)（公告页面截图）*

Microsoft 确认 `agent-framework` Python 元包 1.26.1 与 1.26.2 曾被未授权上传至 PyPI，且包含会在 Python 启动时执行的凭据窃取代码；两版现已下架，1.26.0 及更早版本不受影响。官方要求安装过受影响版本的机器、容器或 CI 作业按已失陷处理：轮换所有可访问凭据、从干净镜像重建，并审查 11 月 17 日以来的云端与 CI 审计日志。独立的 PYSEC-2026-4388 记录进一步确认恶意 `.pth` 文件、包哈希与外传指标。

**为什么值得关注：** 智能体框架通常持有云身份、模型 API Key、代码仓库和 CI/CD 权限；一次元包供应链入侵即可横跨整个自主开发执行面，凸显锁版本、可复现构建和短生命周期凭据的必要性。

- **原文：** [Microsoft Agent Framework repository update](https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-repository-update/)
- **交叉核验：** [PYSEC-2026-4388 技术记录](https://www.openadvisories.org/vuln/PYSEC-2026-4388)
- **发布日期：** 2026-11-25

## 4. OpenClaw 2026.11.10 加入深度研究、可追溯知识库与浏览器接管【扩展至 72 小时】

![OpenClaw 2026.11.10 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openclaw/openclaw/releases/tag/v2026.11.10)

*图片来源：[OpenClaw 官方 GitHub Release](https://github.com/openclaw/openclaw/releases/tag/v2026.11.10)（发布页面截图）*

OpenClaw 2026.11.10 默认启用便携式 Deep Research，可组合网页与本地文档、在来源冲突时并列引文并保留未解决问题，符合条件的任务还能跨 Gateway 重启恢复。新增的可选 Knowledge 插件把对话、会议、笔记与文件整理为本地 Markdown 知识库，并通过时间线、来源摘录和 Git 检查点保留决策沿革。Browser handoff 则允许用户在登录、2FA、CAPTCHA 或敏感表单处接管智能体控制的浏览器标签页，完成后把同一页面状态交还给智能体。

**为什么值得关注：** 这次更新把长期自治常见的三块短板——证据综合、可修订记忆与人类安全接管——放进同一运行时，显示通用智能体正在从“多工具聊天”转向可持续、可审计的人机协作系统。

## 5. Claude Code 2.1.332 接入 MCP Skills，并强化加载前拦截与运行时可靠性【扩展至 72 小时】

![Claude Code 2.1.332 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.332)

*图片来源：[Anthropic 官方 GitHub Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.332)（发布页面截图）*

Claude Code 2.1.332 以 Beta 形式把 MCP 服务器提供的 Skills 纳入命令菜单，并新增 `PreSkillShellCommand` Hook，使管理员能在技能加载时拒绝其内联 Shell 命令。该版还修复了本地 MCP 服务标准输出泛滥导致终端冻结、SSE MCP 断线后工具持续不可用、重复自动压缩失败造成“Prompt is too long”等问题。与此同时，SendUserMessage 与 Cowork 消息工具的文本可通过新的 OpenTelemetry `assistant_response` 事件进入可观测链路。

**为什么值得关注：** MCP Skills 扩大了编码智能体的可组合能力，但也把供应链与执行边界推到“技能加载”阶段；加载前拦截、运行时限流与遥测因此成为企业部署的关键控制面。

- **原文：** [Claude Code v2.1.332 发布说明](https://github.com/anthropics/claude-code/releases/tag/v2.1.332)
- **发布日期：** 2026-11-25
