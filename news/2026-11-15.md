## 1. Codex CLI 0.169.0：终端工作区加入多侧聊标签与历史任务检索

![Codex CLI 0.169.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openai/codex/releases/tag/rust-v0.169.0)

*图片来源：[OpenAI Codex 官方 GitHub 发布页](https://github.com/openai/codex/releases/tag/rust-v0.169.0)*

Codex CLI 0.169.0 为实验性终端工作区加入可持久化的多个 side-chat 标签，并允许从 agent command center 检索更早的任务。新版本也支持添加和编辑自定义模型提供商、网关引导与设备码登录，同时增加 Ctrl+S 导出诊断 ZIP。修复项覆盖恢复会话时的模型提供商选择、长对话切换期间的 steering、文件名加权模糊搜索，以及 Windows 上空闲 MCP 服务器的 I/O 问题。

**为什么值得关注：** 这次更新把 Codex CLI 从单一对话终端进一步推向可并行、可恢复、可诊断的开发工作区；自定义网关能力也降低了企业接入自有模型路由的门槛。

- **原文：** [Codex CLI 0.169.0 Release](https://github.com/openai/codex/releases/tag/rust-v0.169.0)
- **发布日期：** 2026-11-13（扩展至过去 72 小时）

## 2. Claude Code 2.1.325：修复压缩响应安全问题与子智能体模型错配

![Claude Code 2.1.325 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.325)

*图片来源：[Anthropic Claude Code 官方 GitHub 发布页](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)*

Claude Code 2.1.325 修复了处理 zstd 压缩响应时的安全问题，并增强了 bare repository、独立 git-dir、Android repo worktree 等环境下 security review 与 skills 内联 Git 命令的兼容性。该版本还修复了子智能体指定模型后进入 plan mode 时被错误切换模型的问题，以及使用主模型估算 read/MCP 结果大小导致的上下文判断偏差。对第三方网关、Foundry、异常退出后的近期会话恢复和后台子智能体提示可见性也有多项可靠性修复。

**为什么值得关注：** 编码智能体的风险越来越多地集中在“模型之外”的响应解码、上下文压缩和子智能体调度层；这些修复直接收紧了生产环境中最容易被忽略的边界。

- **原文：** [Claude Code 2.1.325 Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.325)
- **发布日期：** 2026-11-14（扩展至过去 72 小时）

## 3. OpenCode 2.3.0：子智能体默认转为后台执行

![OpenCode 2.3.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anomalyco/opencode/releases/tag/v2.3.0)

*图片来源：[OpenCode 官方 GitHub 发布页](https://github.com/anomalyco/opencode/releases/tag/v2.3.0)*

OpenCode 2.3.0 将子智能体统一改为后台运行：调用后立即返回 session ID，并在空闲时向父智能体报告结果。低详细度模式会折叠工具调用与思考过程，桌面端则新增跳回较早提示的能力。版本同时修复 MCP OAuth 刷新与 localhost 重定向、提供商流式响应丢失已完成内容、本地模型发现和 Copilot 端点等问题。

**为什么值得关注：** “立即返回句柄、异步执行、完成后回报”是可扩展多智能体编排的关键语义，它能减少父智能体阻塞，并让长任务更容易恢复、观察和组合。

- **原文：** [OpenCode 2.3.0 Release](https://github.com/anomalyco/opencode/releases/tag/v2.3.0)
- **发布日期：** 2026-11-13（扩展至过去 72 小时）

## 4. GitHub Copilot CLI 1.0.112：加固子智能体与会话状态隔离

![GitHub Copilot CLI 1.0.112 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/github/copilot-cli/releases/tag/v1.0.112)

*图片来源：[GitHub Copilot CLI 官方发布页](https://github.com/github/copilot-cli/releases/tag/v1.0.112)*

Copilot CLI 1.0.112 修复了子智能体模型选择器状态、不同会话间模型切换提示归属，以及 sessions 侧栏操作意外改变退出状态等问题。子智能体视图现在会清理 escape 与控制字符，插件管理器也能准确呈现仓库插件加载失败。版本还补上了恢复会话时的额度限制检查，并修复名称类似 `toString` 的 MCP 工具读取异常。

**为什么值得关注：** 多会话和多智能体 CLI 的可靠性往往取决于状态是否严格归属原会话；这批修复减少了模型选择串线、终端输出污染和插件失败被掩盖的风险。

- **原文：** [GitHub Copilot CLI 1.0.112 Release](https://github.com/github/copilot-cli/releases/tag/v1.0.112)
- **发布日期：** 2026-11-14（扩展至过去 72 小时）
