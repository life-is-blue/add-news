## 1. FastMCP 4.2 候选版让 Agent Skills 按清单发现、按需读取

![FastMCP 4.2.0a5 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/PrefectHQ/fastmcp/releases/tag/v4.2.0a5)

*图片来源：[FastMCP 官方 GitHub 发布页](https://github.com/PrefectHQ/fastmcp/releases/tag/v4.2.0a5)*

FastMCP 4.2.0a5 新增 `SkillManifestProvider`：服务端可先返回技能的 frontmatter、文件摘要与大小，只有客户端真正读取文件时才加载内容，因此对象存储或数据库里的技能无需为一次 `skills/list` 全量载入。新版还让技能可跨挂载服务器发现并经代理转发，`SkillCatalogProvider` 不再在每次请求时重新哈希所有文件。官方将其标记为 4.2.0 正式版前的最后一个预发布版本，并说明该系列要求 Python 3.11。

**为什么值得关注：** 这把 Skills 从“本地文件夹约定”推进为可远程存储、可验证、可惰性加载的运行时资源，能降低大型技能目录的延迟和内存开销，也更适合多智能体共享。

- **原文：** [FastMCP v4.2.0a5 Release](https://github.com/PrefectHQ/fastmcp/releases/tag/v4.2.0a5)
- **发布日期：** 2026-11-13
- **时间范围：** 过去 24 小时
- **发布状态：** 预发布版本

## 2. Collie 1.28.3 修复 Claude Code Remote Control 导致的移动端消息滞留

![Collie 1.28.3 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/AltanS/collie/releases/tag/v1.28.3)

*图片来源：[Collie 官方 GitHub 发布页](https://github.com/AltanS/collie/releases/tag/v1.28.3)*

Collie 1.28.3 修复 Claude Code 的 Remote Control 状态行出现或消失时，手机端发出的消息无法正常送达的问题。版本还把 WalkyTalky 从全局指令文件迁移到各智能体的 Skills 目录，并修复较长 `/rewind` 列表不能按菜单呈现。官方把 Remote Control 消息问题标为紧急更新。

**为什么值得关注：** 远程控制把编码智能体从桌面延伸到移动端，但状态同步错误会让用户误以为指令已进入执行队列；这类消息交付修复直接影响无人值守任务的可控性。

- **原文：** [Collie v1.28.3 Release](https://github.com/AltanS/collie/releases/tag/v1.28.3)
- **发布日期：** 2026-11-13
- **时间范围：** 过去 24 小时

## 3. Desktop Commander 0.3.3 修补 Remote MCP 身份验证漏洞

![Desktop Commander 0.3.3 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/wonderwhy-er/DesktopCommanderMCP/releases/tag/v0.3.3)

*图片来源：[Desktop Commander 官方 GitHub 发布页](https://github.com/wonderwhy-er/DesktopCommanderMCP/releases/tag/v0.3.3)*

Desktop Commander 0.3.3 修复 Remote MCP 的一项身份验证漏洞，并增加额外的验证与防护措施。该问题由 Blackfish Security 负责任披露并独立验证修复；项目尚未公开可安全转述的完整利用细节。Desktop Commander 的 Remote MCP 能让授权的 AI 客户端从远端调用本机文件与终端能力，因此认证链直接保护高权限操作入口。

**为什么值得关注：** 对能执行命令和读写文件的 MCP 服务而言，身份验证不是普通登录功能，而是核心安全边界；使用 Remote MCP 的部署应优先升级并继续配合系统级隔离。

- **原文：** [Desktop Commander v0.3.3 Release](https://github.com/wonderwhy-er/DesktopCommanderMCP/releases/tag/v0.3.3)
- **发布日期：** 2026-11-12
- **时间范围：** 过去 24 小时

## 4. Context7 MCP 4.7.0 支持分页读取跨版本迁移指南

![Context7 MCP 4.7.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/upstash/context7/releases/tag/mcpb-v4.7.0)

*图片来源：[Context7 官方 GitHub 发布页](https://github.com/upstash/context7/releases/tag/mcpb-v4.7.0)*

Context7 发布 MCP Bundle 4.7.0；该版本与 4.6.0 引入的研究预览协同，使智能体能够分页读取较长的跨版本迁移指南。指南会汇总多个版本的前置条件、codemod、破坏性变化、弃用项、配置变化与公共 API 差异，并为每项结论保留来源。4.7.0 也是读取首屏之后后续页面所需的最低版本。

**为什么值得关注：** 编码智能体常因只看到最新版文档而漏掉跨版本迁移链；把多版本发布说明和 API 差异整理成可分页工具输出，可以显著改善依赖升级任务的完整性与可审计性。

- **原文：** [Context7 MCP Bundle 4.7.0](https://github.com/upstash/context7/releases/tag/mcpb-v4.7.0)；[官方研究预览文档](https://context7.com/docs/howto/research-preview)
- **发布日期：** 2026-11-12
- **时间范围：** 扩展至过去 72 小时

## 5. OpenClaw 2026.11.3 发布安全补丁，收紧 Worker 传输与沙箱图片边界

![OpenClaw 2026.11.3 官方发布说明](https://image.thum.io/get/width/1200/crop/675/noanimate/https://docs.openclaw.ai/releases/2026.11.3)

*图片来源：[OpenClaw 官方发布说明](https://docs.openclaw.ai/releases/2026.11.3)*

OpenClaw 2026.11.3 修复空白指纹情况下的 Worker 传输证书验证、强制沙箱中的图片预览越界，以及凭据暴露风险。该补丁还改善中断或失败更新后的 Gateway 恢复、慢速存储上的备份发现、并发审批归属和大型会话索引的内存压力。官方明确将其列为安全版本，并建议升级。

**为什么值得关注：** OpenClaw 把消息渠道、后台任务和本机能力集中在 Gateway 中；传输认证、沙箱路径和凭据处理一旦失守会跨越多个智能体工作流，因此这次补丁的风险优先级高于普通功能更新。

- **原文：** [OpenClaw v2026.11.3 Release Notes](https://docs.openclaw.ai/releases/2026.11.3)
- **发布日期：** 2026-11-11（Asia/Singapore；GitHub 发布时间为 2026-11-10 UTC）
- **时间范围：** 扩展至过去 72 小时
