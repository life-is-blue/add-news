## 1. OpenClaw 2026.11.5：会话跨重启恢复，失败升级可自动回滚

![OpenClaw 2026.11.5 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openclaw/openclaw/releases/tag/v2026.11.5)

*图片来源：[OpenClaw 官方 GitHub 发布页](https://github.com/openclaw/openclaw/releases/tag/v2026.11.5)*

OpenClaw 2026.11.5 可在 Gateway 重启后保留排队消息、发送权限和最终聊天写入；若 Doctor 或 Gateway 启动失败，已激活更新会自动回滚。大型记忆索引重建与 embedding 批处理错误的恢复得到加强，Claude CLI fallback 和 OpenAI compaction item 冲突也有针对性修复。版本还阻止二进制附件进入提示文本、隐藏带认证信息的浏览器 CDP URL，并在自动化启动前重新检查 owner-private memory 权限。

**为什么值得关注：** 这次更新把“可恢复运行”从聊天记录扩展到升级、模型回退、记忆索引和自动化权限，是长期运行自主智能体所需的基础可靠性能力。

- **原文：** [OpenClaw 2026.11.5 Release](https://github.com/openclaw/openclaw/releases/tag/v2026.11.5)
- **发布日期：** 2026-11-17（过去 24 小时）

## 2. Claude Code 2.1.326：Code Mode 可与 Agent Teams 同时启用

![Claude Code 2.1.326 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.326)

*图片来源：[Anthropic Claude Code 官方 GitHub 发布页](https://github.com/anthropics/claude-code/releases/tag/v2.1.326)*

Claude Code 2.1.326 允许在 Agent Teams 开启时使用 Code Mode，并为不完整的工具规则、会话中新增的 `managed-mcp.json` 和失效插件字段提供更明确的提示。版本修复后台会话丢失 LLM gateway、崩溃后恢复会话缺少历史、低内存时早期对话丢失，以及 Bedrock、Vertex、Foundry 上压缩行为异常等问题。MCP 层还修复了并行工具调用在同一毫秒返回时读取到另一调用结果、近似服务器名称导致提示消失，以及按精确名称加载错误工具等问题。

**为什么值得关注：** Agent Teams 与 Code Mode 的组合提升了多智能体批量工具调用能力，而同一版本同步修复并行 MCP 结果串线，说明编排能力与隔离正确性必须一起演进。

- **原文：** [Claude Code 2.1.326 Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.326)
- **发布日期：** 2026-11-17（过去 24 小时）

## 3. Hermes Agent 0.23.2：耐久子智能体可跨 Gateway 崩溃继续执行

![Hermes Agent 0.23.2 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.2)

*图片来源：[Nous Research Hermes Agent 官方 GitHub 发布页](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.2)*

Hermes Agent 0.23.2 是覆盖 CLI、安装包、Microsoft Store、Docker 与 Hermes Cloud 的稳定补丁版本，汇总了自 0.23.1 以来约 1,989 个合并 PR。版本引入可跨 Gateway 重启或崩溃存活、并能在独立会话中继续的耐久子智能体，同时加入 `hermes fallback check`、每任务 cron 选项和 `ctx.fork_session` 等插件 API。候选阶段修复还覆盖 Desktop/TUI 流式回复无法结束、重连后回复重复或缺失，以及启动恢复时输入丢失或错乱。

**为什么值得关注：** 耐久子智能体把恢复粒度从“恢复主会话”推进到“恢复委派工作单元”，更接近真正可断点续跑的多智能体执行系统。

- **原文：** [Hermes Agent 0.23.2 Release](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.2)
- **发布日期：** 2026-11-17（过去 24 小时）

## 4. Agweb 0.4.0：跨域 iframe 可被智能体观察与操作

![Agweb 0.4.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/paul-nameless/agweb/releases/tag/v0.4.0)

*图片来源：[Agweb 官方 GitHub 发布页](https://github.com/paul-nameless/agweb/releases/tag/v0.4.0)*

Agweb 0.4.0 将最低系统要求从 macOS 26 下调到 macOS 15.4，并把跨域 iframe 纳入页面快照，使智能体可对其中的元素引用执行操作。Stripe 等支付 iframe 可以通过 `fill --secret-cmd` 填入敏感字段，具体数值不会出现在回复中。新版本还加入手动原地更新、工作区重开和标签页前进/后退历史查询。

**为什么值得关注：** 跨域 iframe 长期是浏览器智能体的能力断点；在不把秘密写入对话记录的前提下操作支付字段，展示了更实用的凭据隔离路径。

- **原文：** [Agweb 0.4.0 Release](https://github.com/paul-nameless/agweb/releases/tag/v0.4.0)
- **发布日期：** 2026-11-17（过去 24 小时）

## 5. GitHub Copilot CLI 1.0.113-1 预发布：管理员可禁用内置 Browser Use

![GitHub Copilot CLI 1.0.113-1 官方预发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/github/copilot-cli/releases/tag/v1.0.113-1)

*图片来源：[GitHub Copilot CLI 官方 GitHub 发布页](https://github.com/github/copilot-cli/releases/tag/v1.0.113-1)*

GitHub Copilot CLI 1.0.113-1 是官方预发布版本，新增企业托管设置 `features.browserUse`，管理员可以禁用内置 Browser Use。该策略也适用于已在运行的会话；当前 release notes 只公布这一项变更，因此不将其描述为完整稳定版升级。

**为什么值得关注：** 浏览器工具会把编码智能体的权限从仓库扩展到外部网站与已登录会话，允许管理员即时关闭它，是企业治理中清晰且必要的能力边界。

- **原文：** [GitHub Copilot CLI 1.0.113-1 Pre-release](https://github.com/github/copilot-cli/releases/tag/v1.0.113-1)
- **发布日期：** 2026-11-17（过去 24 小时，预发布）
