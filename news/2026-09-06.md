## 1. OpenClaw 2026.9.2 提升长会话响应与重启恢复能力

## 3. 【扩展至 72 小时】Terminal-Universe 将智能体轨迹还原为可复用开发环境

![Terminal-Universe 论文页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://arxiv.org/abs/2609.04148)

*图片来源：[arXiv 论文页面](https://arxiv.org/abs/2609.04148)*

Terminal-Universe 从终端智能体轨迹中的文件操作历史逆向恢复修改前工作区，再由补全智能体补齐缺失文件和依赖，从而把一次性示范转成可重复执行的训练环境。框架还合成跨代码库任务与多轮需求迭代，作者报告从公开轨迹构造出 3.73 万个任务充分环境。使用该语料微调 Qwen3.5-27B 后，Terminal-Bench 2.1 单轮成绩提高 11.9 个百分点，EvoCode-Bench v2 多轮指标提高 13.8 个百分点。

**为什么值得关注：** 高质量、可执行环境正成为编码智能体后训练的稀缺资源；从既有轨迹“回收环境”能将历史运行数据变成可验证的新任务，降低环境从零构造的成本。

- **原文：** [Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments](https://arxiv.org/abs/2609.04148)
- **发布日期：** 2026-09-03（扩展至过去 72 小时）

## 4. 【扩展至 72 小时】环境进化为终端智能体持续制造更难训练任务

![Environment Evolution for Terminal Agents 论文页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://arxiv.org/abs/2609.04128)

*图片来源：[arXiv 论文页面](https://arxiv.org/abs/2609.04128)*

研究团队提出 environment evolution：在训练期间离策略地逐代提高终端环境难度，使学习信号随模型能力增长而持续存在。系统通过多智能体编排沿三种难度方向演化环境，作者使用 Hy4 Preview、Claude Opus 5 和 GPT-5.6 Sol 的 rollout 验证演化环境更具挑战性。对 Qwen3.6-27B 与 Qwen3.6-35B-A3B 进行长程强化学习后，Terminal-Bench 2.1 成绩分别提高 14.4 和 18.0 个百分点。

**为什么值得关注：** 固定基准很快会被强模型“学会”，而可控的环境课程能持续暴露智能体弱点；这为编码智能体从刷静态题库转向动态、可验证的能力边界训练提供了工程化路线。

- **原文：** [Environment Evolution for Terminal Agents](https://arxiv.org/abs/2609.04128)
- **发布日期：** 2026-09-03（扩展至过去 72 小时）

## 5. 【扩展至 72 小时】DRACO 用动态量表解决长程智能体的信用分配

![DRACO 论文页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://arxiv.org/abs/2609.04094)

*图片来源：[arXiv 论文页面](https://arxiv.org/abs/2609.04094)*

DRACO 面向缺少程序化验证器的长程任务，在训练中动态生成随策略能力变化的评价量表，并把整条轨迹的评价重新分配到相关步骤，形成细粒度 GRPO 优势信号。该方法不训练额外的归因模块；作者报告其在 AppWorld 上比基础模型提高 15.9 个百分点，并在域外 Tau-Bench 上提高 5.3 个百分点。结果来自预印本实验，仍需独立复现。

**为什么值得关注：** 长任务失败往往无法归因到某一个动作，单一终局分数会让强化学习信号过于稀疏；DRACO 展示了在没有可靠验证器时，如何把可解释的多维评价转成逐步训练反馈。

- **原文：** [DRACO: Fine-Grained Credit Assignment with Dynamic Rubrics for Long-Horizon Agent Training](https://arxiv.org/abs/2609.04094)
- **发布日期：** 2026-09-03（扩展至过去 72 小时）
