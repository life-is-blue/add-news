## 1. Codex CLI 0.164.0：预设工作流、企业 MCP 与凭据隔离

![Codex CLI 0.164.0 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openai/codex/releases/tag/rust-v0.164.0)

*图片来源：OpenAI Codex 官方 GitHub Release（页面截图）*

Codex CLI 0.164.0 新增 10 个可复用的 `/presets` 槽位，并允许通过 `/model` 与 `/permissions` 的行内参数直接设定模型、推理强度、速度和权限配置。版本还支持以 Codex 账户授权或独立登录认证企业 MCP 连接，并在受支持的远程 Bash 与 Zsh 快照会话中遮蔽凭据。会话压缩失败、恢复已压缩历史、权限队列及 macOS 沙箱路径检查也得到修复。

**为什么值得关注：** 这次更新同时推进“可复用操作流程”和“企业连接安全”，使 Codex 更接近可治理、可恢复的日常开发控制台，而不只是一次性对话工具。

- **原文：** [Codex CLI 0.164.0 Release](https://github.com/openai/codex/releases/tag/rust-v0.164.0)

## 2. OpenClaw 2026.10.6 强制采用修补后的 Node 运行时

![OpenClaw 2026.10.6 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openclaw/openclaw/releases/tag/v2026.10.6)

*图片来源：OpenClaw 官方 GitHub Release（页面截图）*

OpenClaw 2026.10.6 要求 Node 24.22.1+ 或 26.12.1+，以拒绝由 2026 年 10 月 Node.js 安全更新所处理的泄露证书密钥签发的 TLS 链；Docker 镜像和安装器同步切换至修补版本，旧运行时上的更新会被阻止并提供恢复指引。版本还加强包替换、Gateway 启动所有权回收、跨平台更新恢复，以及工作区迁移与 SQLite 备份的无损校验。

**为什么值得关注：** 对拥有长期凭据、网络访问和插件权限的本地智能体而言，运行时证书链与升级回滚本身就是安全边界；OpenClaw 把这些检查变成强制门槛，而非仅靠用户阅读公告。

- **原文：** [OpenClaw 2026.10.6 Release](https://github.com/openclaw/openclaw/releases/tag/v2026.10.6)
- **发布日期：** 2026-10-22 12:53 UTC（新加坡时间 20:53，过去 24 小时）

## 3. Claude Code 2.1.309 修补多处沙箱与权限绕过边缘路径

![Claude Code 2.1.309 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.309)

*图片来源：Anthropic Claude Code 官方 GitHub Release（页面截图）*

Claude Code 2.1.309 修复了沙箱 Bash 在每次命令前于沙箱外加载 shell 启动文件的问题，并处理 macOS 中经符号链接访问时 `denyWrite` 规则未作用于真实路径的缺陷。更新还阻止沙箱命令或自动接受的编辑修改 `--mcp-config` 文件，补齐复合 Bash 命令、重定向、worktree 隔离及配置目录符号链接等权限检查边界。

**为什么值得关注：** 这些缺陷都位于“规则描述的路径”与“命令实际触达的对象”之间；修补它们能降低编码智能体借助 shell、重定向或符号链接越过预期权限的风险。

- **原文：** [Claude Code 2.1.309 Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.309)
- **发布日期：** 2026-10-22 22:18 UTC（新加坡时间 2026-10-23 06:18，过去 24 小时）

## 4. Cloudflare Agents SDK 0.30.0 让 PiHarness 可从崩溃与存储错误中恢复

![Cloudflare Agents SDK 0.30.0 发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/cloudflare/agents/releases/tag/agents%400.30.0)

*图片来源：Cloudflare Agents 官方 GitHub Release（页面截图）*

Cloudflare Agents SDK 0.30.0 升级至 Pi 1.4，并让 PiHarness 在任务休眠时释放 Durable Object；任务超过重启上限后会进入 `parked` 状态，可由 `retry()` 明确重跑。存储错误不再导致后续所有调用持续失败，唤醒任务也会在步骤失败后保留并退避重试；但新存储模式无法回滚到 Pi 1.3。

**为什么值得关注：** “崩溃后是否重复副作用、如何停止崩溃循环、何时安全重试”是长时智能体的核心可靠性问题；该版本给出了明确的停放、恢复和不可逆迁移语义。

- **原文：** [Cloudflare Agents SDK 0.30.0 Release](https://github.com/cloudflare/agents/releases/tag/agents%400.30.0)
- **发布日期：** 2026-10-22 11:29 UTC（新加坡时间 19:29，过去 24 小时）
