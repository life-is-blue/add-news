## 1. Codex CLI 0.171.0：工作区默认启用，支持远程续跑非交互任务

![Codex CLI 0.171.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/openai/codex/releases/tag/rust-v0.171.0)

*配图来源：[OpenAI Codex 官方 GitHub Release](https://github.com/openai/codex/releases/tag/rust-v0.171.0)*

Codex CLI 0.171.0 默认启用 TUI 工作区，在主对话旁提供可搜索的文档预览、图片预览和子智能体转录，并新增 `codex exec --remote <ADDR>`，可在现有 app server 上启动或恢复非交互会话。版本同时加入 TUI 远程控制与配对入口、自定义 MCP 状态栏，并修复切换或恢复会话时草稿、排队消息、权限配置与进行中编辑丢失的问题。

**为什么值得关注：** Codex 正从“单窗口命令行助手”演进为可观察、可远程控制的多智能体工作区；远程续跑与状态恢复尤其适合 CI、长时间实现任务和架构—实现—验收式协作。

- **原文：** [Codex CLI 0.171.0 Release Notes](https://github.com/openai/codex/releases/tag/rust-v0.171.0)
- **发布日期：** 2026-11-20（新加坡时间）

## 2. Claude Code 2.1.329：统一展示计划任务与 Fork，并加固 Code Review

![Claude Code 2.1.329 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/anthropics/claude-code/releases/tag/v2.1.329)

*配图来源：[Anthropic Claude Code 官方 GitHub Release](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)*

Claude Code 2.1.329 将当前会话的计划任务、`/loop` 唤醒、Goal 和 conversation forks 纳入 `/tasks`，并让 MCP 页面直接显示远程 HTTP 服务器拒绝连接时的 JSON-RPC 错误。它还修复 `/code-review <PR>` 偶尔审查当前分支而非目标 PR、Code Mode 内存失控、后台智能体停止失败，以及远程会话和自托管 Runner 的多项状态与 Git 安全问题。

**为什么值得关注：** 把循环、目标、分叉和后台工作放进同一任务视图，提升了自主开发流程的可管理性；同时，确保评审对象真的是指定 PR，是自动化代码验收最基本却极关键的正确性要求。

- **原文：** [Claude Code 2.1.329 Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)
- **发布日期：** 2026-11-20（新加坡时间）

## 3. OpenClaw 2026.11.6：集中修复网关恢复、多智能体状态与更新链

![OpenClaw 2026.11.6 官方发布说明](https://image.thum.io/get/width/1200/crop/675/noanimate/https://docs.openclaw.ai/releases/2026.11.6)

*配图来源：[OpenClaw 官方发布说明](https://docs.openclaw.ai/releases/2026.11.6)*

OpenClaw 2026.11.6 是包含 386 个 PR 的稳定补丁版，覆盖安装、更新、消息、模型提供商、插件与原生应用。关键修复包括 Gateway 重启时保留完成与待输入状态、降低多智能体 PostgreSQL 空闲连接、恢复子会话审批和问题在父会话中的可见性，并改进更新中断、状态锁释放、数据库检查与插件迁移的恢复路径。

**为什么值得关注：** 对长期运行的智能体平台而言，失败恢复与数据库租约往往比新功能更决定生产可用性；这一版明显聚焦重启、并发状态和更新链，降低“任务仍在跑但平台已无法恢复”的风险。

- **原文：** [OpenClaw 2026.11.6 Release Notes](https://docs.openclaw.ai/releases/2026.11.6)
- **发布日期：** 2026-11-20（新加坡时间）

## 4. Hermes Agent 0.23.3：重构提示缓存生命周期与存储层

![Hermes Agent 0.23.3 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.3)

*配图来源：[NousResearch Hermes Agent 官方 GitHub Release](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.3)*

Hermes Agent 0.23.3 汇总约 370 个 PR，引入统一的提示缓存生命周期控制器，可在长工具调用期间维持缓存，并在一小时缓存到期前压缩空闲会话；压缩会归档被丢弃的工具结果，主动工具结果裁剪也默认开启。该版还将存储拆分到持久化接口及 SQLite 后端，加入队友等待状态、GPT-6.2 模型支持，并更新 oauthlib、OpenTelemetry 和 Tornado 等安全依赖。

**为什么值得关注：** 缓存、压缩和工具结果裁剪是长程智能体成本与可靠性的核心三角；Hermes 将它们纳入同一生命周期控制，同时抽象持久化层，为后续跨进程和多节点运行打下基础。

- **原文：** [Hermes Agent 0.23.3 Release Notes](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.3)
- **发布日期：** 2026-11-20（新加坡时间）

## 5. Gemini CLI 0.70.0：加强 Worktree 恢复与系统 MCP 安全检查

![Gemini CLI 0.70.0 官方发布页](https://image.thum.io/get/width/1200/crop/675/noanimate/https://github.com/google-gemini/gemini-cli/releases/tag/v0.70.0)

*配图来源：[Google Gemini CLI 官方 GitHub Release](https://github.com/google-gemini/gemini-cli/releases/tag/v0.70.0)*

Gemini CLI 0.70.0 修复认证重启后丢失所选 worktree、会话恢复失败却提前切换工作目录，以及空模型回复后工具轮次中断状态丢失的问题。它还会跳过命令权限不安全的系统级 MCP 服务器，改用线性时间的策略参数正则实现，并让无法解析变量展开的 shell 命令继续保持 `ASK_USER`。

**为什么值得关注：** Worktree 和恢复语义直接影响并行开发是否会写错目录；系统 MCP 权限检查与线性时间策略匹配，则同时收紧供应链入口并降低恶意或复杂规则造成资源耗尽的风险。

- **原文：** [Gemini CLI 0.70.0 Release Notes](https://github.com/google-gemini/gemini-cli/releases/tag/v0.70.0)
- **发布日期：** 2026-11-20（新加坡时间）
