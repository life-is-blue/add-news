## 1. Cursor 市场分发恶意 Claude Code 扩展，尝试植入持久化 SSH 后门

- **分类**：Coding Agent / 插件供应链 / 开发者终端
- **严重度**：严重
- **发布日期**：2026-10-31（北京时间；Cursor 于 10 月 30 日 11:30 PT 更新受影响版本与 IOC）
- **可信度**：多方确认（Cursor 官方公告 + Microsoft 威胁情报 + Reuters）
- **影响对象**：在 Windows 或 macOS 上通过 Cursor VS Code Extension Marketplace 安装或自动更新 `Anthropic.claude-code` 2.1.312、2.1.313 的开发者与企业
- **发生了什么**：Cursor 确认，10 月 29 日约 02:27 至 13:35 PT，其扩展市场提供了被恶意修改的 `Anthropic.claude-code` 2.1.312 和 2.1.313。恶意代码收集主机名、用户名、操作系统、环境变量名称、工作目录、Git 邮箱和公网 IP，尝试把攻击者 SSH 公钥写入 `authorized_keys`、启用 SSH 服务、建立反向隧道，并通过 macOS LaunchAgent 或 Windows 计划任务持久化。Cursor 已下架扩展、关闭并重建市场、轮换密钥，且托管商已关闭攻击者服务器。Microsoft 确认微软 VS Code Marketplace 与 npm 官方 Claude Code 包未受影响，Anthropic 也确认其系统未失陷。Reuters 报道最多约 5,000 名用户可能受影响。
- **为什么值得关注**：这不是仿冒名称的普通恶意插件，而是攻击者借可信市场和正确扩展标识分发篡改包。开发者终端通常同时持有源代码、SSH、Git、云和 CI/CD 凭据；即使反向隧道因权限不足而失败，恶意扩展仍可能已写入公钥、持久化脚本并发送主机信息。单纯卸载扩展不能保证清除后门。
- **建议行动**：
  1. 检查 Cursor 市场安装历史和终端扩展目录，定位 2.1.312、2.1.313；命中设备立即隔离并保全证据。
  2. 按 Cursor 公告检查 `authorized_keys` 中的 `svc-telemetry`、IOC 地址 `134[.]209[.]82[.]225`、反向 SSH 与持久化进程。
  3. 使用 Cursor 官方修复脚本清理；若发现载荷运行或远程访问迹象，优先重建终端，而非仅卸载扩展。
  4. 从可信设备轮换受影响主机可访问的 SSH、Git、云、包仓库、CI/CD 和模型 API 凭据，并撤销现有会话。
  5. 企业应锁定扩展来源、版本与哈希，关闭开发工具的无审查自动更新，并保存市场安装审计日志。
- **原始来源**：
  - [Cursor：Claude Code extension security notice](https://cursor.com/blog/claude-code-extension-security-notice)
  - [Microsoft Security：Inside a malicious Claude Code-branded extension](https://www.microsoft.com/en-us/security/blog/2026/10/30/inside-malicious-claude-code-branded-cursor-extension-persistent-ssh-backdoor/)
  - [Reuters：Cursor says up to 5,000 users affected](https://www.reuters.com/business/media-telecom/cursor-says-up-5000-users-affected-by-tampered-claude-code-extension-2026-10-30/)

## 2. Chainalysis 遭“进攻性智能体技术”入侵，部分客户身份资料被访问

- **分类**：AI 驱动攻击 / 数据泄露 / 区块链调查平台
- **严重度**：高
- **发布日期**：2026-10-31（北京时间；官方公告日期为 10 月 30 日）
- **可信度**：官方确认（Chainalysis；具体智能体工具、入侵路径和受影响规模尚未披露）
- **影响对象**：Chainalysis 客户及其平台用户，尤其执法、交易所、金融机构和加密资产调查人员
- **发生了什么**：Chainalysis 表示，本月检测到外部攻击者使用其所称的“offensive agentic techniques”未经授权进入公司系统和内部工具。攻击者访问了部分客户用户 ID、姓名、电子邮件地址和组织角色标签。公司目前没有发现调查内容（图谱、笔记、案件）、交易或查询结果、明文密码、MFA 秘密或会话令牌被未授权访问的证据，并强调该事件与 Binance 约 63 亿美元失窃无关。Chainalysis 已通知客户，但尚未公开具体攻击链、所用模型、IOC、事件日期或受影响记录数量。
- **为什么值得关注**：这是受影响企业直接使用“进攻性智能体技术”描述真实入侵的罕见公开案例。即便当前确认的数据字段相对有限，姓名、邮箱和角色标签也足以帮助攻击者识别调查人员、高权限用户和加密资产合规团队，发起高度定向的钓鱼、冒充或账户恢复攻击。缺乏技术细节意味着外界暂时无法独立判断 AI 在攻击中是自主执行器、编排工具还是效率增强组件。
- **建议行动**：
  1. Chainalysis 客户核对官方通知，确认本组织受影响用户，并对相关账户提高风险等级。
  2. 强制使用抗钓鱼 MFA，审查登录、令牌创建、API 使用与账户恢复日志；对异常会话和长期令牌执行撤销。
  3. 向员工预警以 Chainalysis、执法合作、Binance 调查或合规核查为主题的定向钓鱼。
  4. 不因官方称“未发现”调查内容或凭据被访问而停止监测；该表述是当前证据边界，不是绝对排除。
  5. 等待并跟进 Chainalysis 的受影响记录明细、IOC 与根因复盘，再决定是否需要更广泛的凭据轮换和调查隔离。
- **原始来源**：
  - [Chainalysis：Security Incident Information](https://www.chainalysis.com/blog/security-incident-october-30/)

## 3. Ivanti Connect Secure 三漏洞链被在野利用，可取得未经认证的 root 访问

- **分类**：在野漏洞 / 边界设备 / 攻击链
- **严重度**：严重
- **发布日期**：2026-10-31（北京时间；CISA 于 10 月 30 日加入 KEV）
- **可信度**：官方确认（CISA KEV + Ivanti + 加拿大网络安全中心；Volexity 原始攻击研究）
- **影响对象**：运行 Ivanti Connect Secure 22.8、25.1 受影响版本的政府、企业、托管服务与关键基础设施组织
- **发生了什么**：CISA 将 **CVE-2026-111357** 和 **CVE-2026-118527** 加入 KEV，并明确指出它们可与此前已入列的认证绕过漏洞 **CVE-2026-104935** 串联。攻击链可从无需有效凭据的外部入口开始，上传攻击者控制内容并将权限提升到 root。Ivanti 已确认有限在野利用；公开研究显示攻击者偏向窃取凭据、Active Directory 元数据、管理员密码和 BitLocker 恢复密钥，而非部署显眼的传统恶意软件。受影响版本包括低于 25.1.1.3、25.1.3.1 和 22.8R2.6 的分支。
- **为什么值得关注**：VPN 与安全网关本身位于网络信任边界，root 级失陷可让攻击者窃取身份材料、观察内部流量并作为后续横向移动入口。链中单个漏洞的 CVSS 可能不高，但组合后的真实风险远高于逐项评分；先前只修复 CVE-2026-104935 的设备可能仍未关闭完整攻击路径。
- **建议行动**：
  1. 立即升级到 Ivanti 公告列出的完整修复版本：25.1.1.3、25.1.3.1、22.8R2.6 或更高版本。
  2. 运行 Ivanti Integrity Checker Tool，并检查网关上的异常文件、配置变化、系统账户、凭据读取和对 AD 的可疑查询。
  3. 对补丁前暴露的设备按“可能已失陷”处理；仅升级不能清除已取得的 root 持久化。
  4. 轮换网关保存或可访问的本地、LDAP/AD、RADIUS、证书和 BitLocker 恢复材料，并排查下游横向移动。
  5. 无法及时修复时将设备从互联网撤下或停止使用，不以 WAF 或访问控制列表替代厂商修复。
