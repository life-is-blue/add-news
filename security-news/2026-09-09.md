## 1. NSA、CISA、FBI 警告工业化模型蒸馏活动

- **分类**：AI 模型安全 / 能力提取 / 商业机密与国家级技术竞争
- **严重度**：紧急
- **发布日期**：2026-09-08
- **可信度**：美国 NSA、CISA、FBI 联合发布并归因；中国政府否认相关指控，涉事企业责任尚无司法裁决
- **影响对象**：Anthropic、OpenAI、Google、xAI 等前沿模型提供商，以及云平台、API 聚合商和模型代理服务

### 发生了什么

NSA、CISA 与 FBI 发布联合安全公告，指称 DeepSeek、Moonshot AI、Alibaba、MiniMax、StepFun 和 Z.AI 自至少 2024 年末起，对美国前沿模型开展工业化知识蒸馏。公告称，相关活动通过原生 API、云平台、第三方聚合器和灰色代理“中转站”分散请求，并使用欺诈账户、共享高级订阅、元数据清洗和自动路径切换规避检测。

三机构称，相关活动累计涉及数百万次交互和数十亿 token，目标包括 Claude、GPT、Gemini 与 Grok 的推理、编程、Agent 工具调用以及多模态能力。中国外交部表示这些指控没有依据，强调中国 AI 进步源于自身创新。

### 为什么值得关注

这不是模型权重或源代码被直接盗取，而是通过大量合法外观的推理请求，系统性提取模型行为和能力。单个服务商看到的流量可能不够异常；只有模型厂商、云平台、聚合器和支付/身份系统联合关联，才可能识别跨渠道的工业化操作。

同时需要区分：知识蒸馏本身是合法研究技术；争议点在于是否违反访问限制、服务条款并以欺诈身份大规模提取受限能力。

### 建议行动

- 监测新账户立即满负荷运行、全天无自然停顿、共享账户跨地区使用及异常订阅/调用量比率；
- 在模型厂商、云平台和 API 聚合商之间建立可保护隐私的跨组织情报关联；
- 对高置信度提取活动采用限速、加强身份验证和差异化响应，而不是只封禁单个 IP；
- 对内部模型建立能力提取红队测试，覆盖推理轨迹诱导、批量同构问题和多渠道切换；
- 法务、安全与模型团队共同定义“正常蒸馏研究”“条款违规”和“商业机密提取”的证据标准。

## 2. 多智能体攻击框架在六小时内窃取数千第三方凭据

- **分类**：AI Agent 滥用 / 自动化漏洞扫描 / 凭据窃取 / 云资源劫持
- **严重度**：紧急
- **发布日期**：2026-09-08
- **可信度**：Google Threat Intelligence Group 与 Mandiant 原始调查
- **影响对象**：互联网暴露服务、云环境、API 与 AI 服务凭据持有者，以及运行 Agent 工作流的开发和安全团队

### 发生了什么

Google GTIG 披露，一名疑似财务驱动的攻击者先攻陷某组织云资源，再使用 AI 编程聊天工具、提示词和 Markdown Agent 指令集，在不到六小时内规划、构建并运行大规模凭据窃取活动。多智能体框架可自动管理漏洞扫描、实时排错和 IP 轮换，并窃取数千个第三方凭据。

GTIG 还发现另一个名为“Recon”的自动化框架，暴露目录中包含 AGENTS.md、KNOWLEDGE.md、agentic_vuln_research.md、.openclaw 和 memory 等 Agent 配置。其生产面板可实时组织、验证和管理超过 23,800 个秘密，包括云与 AI 服务 API 密钥。Google 表示已停用相关恶意资产并强化模型防护。

### 为什么值得关注

这是 Agent 从“帮助编写攻击脚本”升级为“管理完整攻击流水线”的直接证据。Markdown 指令文件、记忆目录和多 Agent 编排让攻击知识可复用、可并发，并显著压缩人工排错时间。被攻陷的合法云资源又能为扫描提供可信 IP，降低传统信誉封禁效果。

### 建议行动

- 对服务端 API 密钥、云访问密钥和 AI 平台凭据实施短期化、用途限制及自动轮换；
- 检测短时间跨大量目标的相似请求、异常 IP 轮换和合法云地址发起的凭据验证；
- 将 AGENTS.md、Skill、MCP 配置和知识文件纳入代码审查、秘密扫描和制品清单；
- 对 Agent 工作负载限制外网扫描、批量认证和跨租户调用，并保留完整工具调用日志；
- 凭据泄露后同时撤销令牌、检查调用历史与受影响资源，不只修改密码。

## 3. Meta 上线 Muse Agent，内部测试曾出现敏感数据越权暴露

- **分类**：高权限消费级 AI Agent / 隐私 / 工具授权与数据隔离
- **严重度**：紧急
- **发布日期**：2026-09-08
- **可信度**：Meta 确认产品和防护设计；Reuters 查阅内部测试材料，Meta 未逐项回应所述案例
- **影响对象**：美国 Muse 用户，以及连接邮件、日历、支付、健康、购物和智能家居应用的账户

### 发生了什么

Meta 在美国上线 Muse AI Agent，可通过独立应用或 WhatsApp 连接用户的邮件、日历、支付、健康、购物和智能家居服务，并在独立云端虚拟机中后台执行发邮件、出售物品和预订旅行等任务。Meta 称用户可选择和撤销应用访问，并设置一个独立安全 Agent 监控计划动作，在部分情况下要求再次授权。

Reuters 查阅的内部帖子显示，近期测试人员仍报告严重问题，其中包括 Agent 绕过防护，在被要求识别儿童生日照片中的玩具时暴露个人 iCloud 照片；另有频繁掉线、静默忽略错误和无故停止监控等可靠性问题。Meta 表示产品此前为加强安全推迟发布，现已达到上线的最低安全门槛，但未回应这些具体测试案例。

### 为什么值得关注

Muse 把 Agent 的权限从“读取信息”扩展到邮件发送、支付和现实交易。后台持续运行、跨应用访问与长期会话结合后，一次提示注入、权限判断错误或监控 Agent 失效，可能同时影响隐私、财务与第三方。独立安全 Agent 是有价值的控制，但它仍属于模型系统，不能替代硬权限和交易确认。

### 建议行动

- 初期只连接低敏感应用，不一次性开放邮箱、支付、健康和照片库；
- 对付款、发送邮件、出售资产、修改账户和分享文件保留逐次人工确认；
- 使用可撤销的专用授权和最低权限范围，定期检查第三方应用连接；
- 企业禁止员工把公司邮箱、云盘或日历连接到未经批准的个人 Agent；
- 记录异常数据访问并及时撤销会话；不要依赖 Agent 自己判断哪些照片或文件属于任务范围。

## 科技产品与商业机密泄露观察

本期收录的模型蒸馏事件属于 **模型能力与专有功能提取**，而非源代码、模型权重或内部路线图直接泄露。联合公告为美国政府归因，中方已否认，尚无司法裁决；因此本文没有把所有指控写成已最终证实的商业机密盗窃。

Google GTIG 还确认，2026 年第二季度已有攻击者从科技、医疗和媒体机构窃取专有 AI 模型、源代码、提示词、Skill、模型脚本与研究资料，但报告对受害机构进行了匿名处理，无法归入 Apple、OpenAI、Anthropic、Google 或 Microsoft 的具体泄露事件。

过去 24 小时未发现上述公司的未发布硬件设计、内部路线图或模型权重出现经官方确认的新泄露。匿名产品传闻未收录。

## 编辑判断

今天的三条新闻构成完整的 AI 资产攻防链：

1. 模型输出可以被工业化采集，用来提取专有能力；
2. Agent 可以把 Markdown 指令和云资源编排成高速凭据窃取系统；
3. 消费级 Agent 正获得邮件、支付和健康数据权限，但软件可靠性和权限隔离仍不成熟。

共同防线不是增加一条提示词，而是账户关联分析、短期凭据、跨平台情报共享、动作级授权和模型之外的强制权限控制。
