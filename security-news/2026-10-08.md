## 1. CrowdStrike披露韩国银行攻击使用ARTEX与多种AI编程工具

- **分类**：AI智能体 / Coding Agent滥用 / 金融业攻击
- **严重度**：高
- **发布日期**：2026-10-07至2026-10-08
- **可信度**：初步披露；攻击链证据较强，个人身份与地域归因仅为中等置信度
- **影响对象**：至少九家遭攻击或报告异常的韩国金融机构；使用公开Agent渗透框架及AI编程工具的防守团队
- **发生了什么**：CrowdStrike在关联攻击基础设施中发现ARTEX实例、开放目录、记忆文件及AI编程会话记录，认为攻击者在9月底至10月初针对韩国金融机构实施了广泛活动并造成数据外传。ARTEX主要连接DeepSeek v4.1-flash，攻击者还使用GLM-5.3、Grok 4.6和Claude Code会话辅助操作。CrowdStrike根据中文提示、工具使用和会话中留下的个人资料，评估操作者可能是位于中国广东的26岁个人、具有经济动机；该判断尚未得到执法机构确认，相关电话号码接听者也否认知情。
- **为什么值得关注**：这不是“AI自主完成攻击”的充分证据，而是单个操作者利用Agent和Coding工具并行化侦察、漏洞利用、记录整理与目标切换的现实案例。攻击者自身留下的会话与记忆文件也表明，Agent日志既是取证资产，也可能反向暴露操作者。
- **建议行动**：
  1. 金融机构优先排查ARTEX默认特征、关联基础设施、异常API调用、自动生成的攻击报告和批量扫描行为。
  2. 将AI工具会话、Agent记忆、工具调用和网络出口纳入日志留存与威胁狩猎，关联身份、代码仓库和目标资产。
  3. 对互联网暴露的贷款查询、移动办公及经纪人服务实施强身份验证、速率限制和异常查询检测。
  4. 归因与处置分离：立即阻断可验证基础设施，但不要仅凭语言、工具来源或会话自述认定国家背景。
- **原始来源与补充来源**：

  - [Reuters：攻击规模、归因置信度与相关方回应](https://www.reuters.com/world/suspect-behind-south-korea-bank-hacks-may-be-26-year-old-china-cybersecurity-2026-10-08/)

## 2. GhostAction再次入侵772个GitHub仓库，恶意Actions工作流成功外传秘密

- **分类**：GitHub Actions / CI/CD / 软件供应链
- **严重度**：严重
- **发布日期**：2026-10-07
- **可信度**：初步披露，有可复现仓库历史与工作流运行记录
- **影响对象**：2026年8月31日至9月30日期间被植入恶意工作流的772个公开仓库、373个用户和组织，以及依赖这些仓库或其发布流程的下游用户
- **发生了什么**：GitGuardian披露GhostAction新一轮活动。攻击者疑似使用被盗GitHub凭据，以受害者身份提交名为 `github_actions_security.yml` 或 `security-check.yml` 的工作流，并从既有配置历史中提取 `${{ secrets.NAME }}` 名称，再将运行时秘密发送到 `193.32.204.199`。772个仓库的工作流共针对2,577项秘密；GitHub拦截或要求批准了多数运行，但研究者确认336次运行成功，涉及13个仓库并外传26项秘密。截至10月5日，公开历史中仅124个仓库被有效清理。
- **为什么值得关注**：攻击不需要修改应用代码，只需向CI/CD配置加入看似正常的“安全工作流”。被盗的SSH、Azure、AWS、容器仓库、npm、PyPI和GitHub凭据可继续用于服务器入侵、恶意发布与跨生态供应链扩散。
- **建议行动**：
  1. 全局搜索 `github_actions_security.yml`、`security-check.yml`、提交信息“Add Github Actions Security workflow”及目标IP；同时检查已删除文件的Git历史。
  2. 不要只删除工作流：轮换其引用过的全部秘密、吊销PAT/OAuth/App令牌，并核查云端和发布平台使用记录。
  3. 检查8月31日以来的Actions运行、审批、出站连接和异常提交者会话；受影响版本或制品应重新构建、签名和验证。
  4. 限制工作流写权限，启用强MFA、短期OIDC凭据、环境审批与出站网络控制，避免长期发布密钥暴露给普通工作流。
- **原始来源与补充来源**：
  - [GitGuardian原始研究：GhostAction 2026新一轮攻击](https://blog.gitguardian.com/ghostaction-github-actions-supply-chain-attack-returns/)

## 3. vm2的NodeVM危险模块漏拦截可直接逃逸到宿主机命令执行

- **分类**：开发依赖 / 沙箱逃逸 / 远程代码执行
- **严重度**：严重（CVSS 3.1：10.0）
- **发布日期**：2026-10-07（CVE公开）
- **可信度**：官方确认
- **影响对象**：使用 `vm2` NodeVM执行不可信JavaScript，并配置 `builtin: ['*']`、显式允许 `child_process` 或使用类似通配减法规则的服务、插件平台、评测系统与构建工具
- **发生了什么**：CVE-2026-93605显示，NodeVM的 `DANGEROUS_BUILTINS` 禁止列表拦截了多个可触达宿主机的Node.js模块，却遗漏最直接的 `child_process`。在受影响配置中，沙箱代码可调用 `execSync` 等接口，以宿主进程权限执行任意命令。影响3.12.1之前版本，修复版为3.12.1。
- **为什么值得关注**：不少代码执行、插件和AI评测服务把JavaScript沙箱视为安全边界。一旦逃逸，攻击者获得的不是模型输出控制，而是运行用户权限下的文件、网络、云凭据与构建环境访问能力。
- **建议行动**：
  1. 升级 `vm2` 至3.12.1或更高版本，确认锁文件与容器镜像中不存在旧版传递依赖。
  2. 搜索NodeVM配置中的 `builtin: ['*']`、`child_process`及通配减法模式；即使升级后也应遵循最小允许列表。
  3. 将不可信代码放入独立容器或微虚拟机，使用非特权账户、只读文件系统、最小挂载和默认拒绝网络出口。
  4. 检查沙箱宿主上的异常子进程、shell调用、凭据读取和外联；若曾运行不可信代码，按宿主失陷情景处置。
- **原始来源与补充来源**：
  - [GitHub Advisory：GHSA-pq68-rvw4-xp4r](https://github.com/patriksimek/vm2/security/advisories/GHSA-pq68-rvw4-xp4r)
  - [GitLab Advisory Database：CVE-2026-93605影响与修复版本](https://advisories.gitlab.com/npm/vm2/CVE-2026-93605/)
  - [vm2修复版本与变更说明](https://github.com/patriksimek/vm2/releases)

## 4. Backstage TechDocs恶意配置可在文档构建主机执行命令

- **分类**：开发者门户 / CI/CD / 配置注入
- **严重度**：高（CVSS 3.1：7.7）
- **发布日期**：2026-10-07
- **可信度**：官方确认
- **影响对象**：使用 `@backstage/plugin-techdocs-node` 且允许用户注册Catalog实体、由TechDocs构建文档的Backstage部署
- **发生了什么**：CVE-2026-106510允许有权注册Catalog实体的已认证用户提交特制 `mkdocs.yml`，利用 `markdown_extensions` 配置在TechDocs构建文档时，于构建主机执行任意操作系统命令。官方修复分支包括1.14.6和1.15.4；Backstage整体发行版已提供相应修复版本。
- **为什么值得关注**：开发者门户通常连接源代码托管、云平台、制品库与CI/CD系统。文档构建配置常被视为低风险内容，但构建机上的命令执行可转化为凭据窃取、内部网络访问和发布链污染。
- **建议行动**：
  1. 将 `@backstage/plugin-techdocs-node` 升级到受支持分支的修复版本（1.14.6、1.15.4或更高版本），并更新Backstage发行版。
  2. 在修复前限制Catalog实体注册权限，暂停处理来自不可信仓库的TechDocs构建。
  3. 隔离TechDocs构建器，移除云端长期凭据与Docker socket，限制网络出口和文件系统写入。
  4. 搜索异常 `markdown_extensions`、未知Python模块与构建期间产生的子进程；发现可疑构建时轮换构建机可访问的秘密。
- **原始来源与补充来源**：
  - [GitHub Advisory：GHSA-4488-j8vj-vqqv](https://github.com/backstage/backstage/security/advisories/GHSA-4488-j8vj-vqqv)
  - [GitLab Advisory Database：CVE-2026-106510](https://advisories.gitlab.io/npm/%40backstage/plugin-techdocs-node/CVE-2026-106510/)
  - [Backstage修复提交](https://github.com/backstage/backstage/commit/02cd7cdbb18b687446277b5602adaee7f1d53cbb)
