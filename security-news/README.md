# 每日安全与科技泄露简报

本目录收录经过筛选与交叉核验的网络安全、AI 智能体安全和科技行业信息泄露事件。

## 目录约定

```text
security-news/
├── README.md
└── YYYY-MM-DD.md
```

每天生成一个独立 Markdown 文件，日期以北京时间（Asia/Shanghai）为准。

## 选题范围

### 1. 网络与 AI 安全

- AI 智能体、Coding Agent、MCP、Skill 与插件安全
- 软件供应链、开源依赖、GitHub Actions 与 CI/CD 安全
- 已在野利用漏洞、零日漏洞与重大安全更新
- 重大数据泄露、身份凭据泄露与隐私事件
- 关键基础设施和具有广泛影响的网络攻击

### 2. 科技行业信息泄露

- 未发布产品的设计图、原型、零部件和供应商资料
- 源代码、模型参数、内部路线图与商业机密
- 员工、承包商或供应商导致的信息泄露
- 黑客攻击获取并公开的内部文件

普通产品传闻、匿名爆料和缺乏证据的参数预测不视为已确认的信息泄露。

## 收录标准

1. 优先覆盖过去 24 小时；高质量内容不足时扩展到 72 小时并注明。
2. 每日建议收录 3–5 条，不为凑数加入低质量内容。
3. 同一事件的重复报道合并，优先引用官方公告、CVE、补丁或原始研究。
4. 媒体报道用于补充背景，重要说法至少经过一个独立可靠来源核验。
5. 若当天没有符合标准的科技产品泄露，明确写“无符合标准的新事件”。

## 可信度标记

- **官方确认**：由受影响机构、监管部门或安全响应机构确认。
- **多方确认**：至少两个相互独立的可靠来源提供一致证据。
- **初步披露**：已有技术证据，但事件仍在调查。
- **未经证实**：只进入观察区，不作为事实写入正文。

## 每条新闻字段

- 分类
- 严重度
- 发布日期
- 可信度
- 影响对象
- 发生了什么
- 为什么值得关注
- 建议行动
- 原始来源与补充来源
