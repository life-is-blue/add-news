## 今日要点

### 1. Veeam Backup & Replication 低权限角色可远程执行 SYSTEM 代码（72 小时扩展）

- **分类：** 严重漏洞 / 备份与灾难恢复基础设施
- **严重度：** 严重（CVSS v4.0 9.4）
- **发布日期：** 2026-10-09（权威机构预警；厂商补丁于 10 月 6 日发布）
- **可信度：** 官方确认（Veeam 安全公告、CSA Singapore 预警）
- **影响对象：** Veeam Backup & Replication 12.3.2.4854 及更早的所有版本 12 构建；版本 13 不受影响
- **发生了什么：** CVE-2025-64393 是 Mount Service 对不可信数据的不安全反序列化漏洞。已经取得低权限 `Backup Viewer` 角色的攻击者，可通过网络在 Veeam Backup Server 上执行任意代码，最终权限为 `SYSTEM`。Veeam 已在 12.3.2 P4（build 12.3.2.4934）修复；目前引用来源未报告在野利用。
- **为什么值得关注：** 备份服务器通常同时拥有生产系统、虚拟化平台和备份库的高价值访问能力。攻击者一旦从只读角色提升为主机 `SYSTEM`，可能破坏备份、窃取凭据或阻断勒索软件恢复路径；“需要低权限账户”并不能显著降低真实风险。
- **建议行动：** 立即升级至 12.3.2 P4 或迁移至不受影响的版本 13；在升级前限制 Mount Service 和管理接口的网络来源，并复核所有 `Backup Viewer` 账户。保存 Veeam、Windows、身份与网络日志，检查异常服务调用、进程创建、密钥访问及备份删除行为；如发现异常，先隔离服务器并验证离线/不可变备份。
- **原始来源与补充来源：**
  - [Veeam KB4934](https://www.veeam.com/kb4934)
  - [CSA Singapore：Critical Vulnerability in Veeam Backup & Replication](https://www.csa.gov.sg/alerts-and-advisories/alerts/al-2026-138/)
  - [NVD：CVE-2025-64393](https://nvd.nist.gov/vuln/detail/CVE-2025-64393)

### 2. AhsayCBS 未修补漏洞已被串联利用，攻击者投放 WebShell 与挖矿程序（72 小时扩展）

- **分类：** 在野利用 / 备份平台 / MSP 供应链
- **严重度：** 严重
- **发布日期：** 2026-10-09（攻击活动公开）
- **可信度：** 初步披露（Huntress 事件响应观测；CVE 已登记，厂商截至披露时尚未提供有效修复确认）
- **影响对象：** 对外暴露 AhsayCBS 管理界面的 MSP、系统集成商及其下游客户；研究人员确认最新 10.3.4 仍受影响
- **发生了什么：** Huntress 自 10 月 7 日起在至少五家机构观察到攻击者串联 CVE-2026-105133 身份验证绕过与 CVE-2026-105134 操作系统命令注入，随后执行侦察、部署 JSP WebShell，并下载伪装为 `msedge.exe` 的 XMRig 挖矿程序。持久化服务名为 `MicrosoftEdgeUpdateSvc`；攻击者还使用 PowerShell 脚本在任务管理器打开时暂停挖矿以逃避发现。尽管部分数据库曾显示漏洞在旧版本修复，Huntress 验证当前 10.3.4 仍然可受影响。
- **为什么值得关注：** AhsayCBS 常由 MSP 集中管理多家客户备份。被攻陷的备份平台不仅消耗算力，还可能成为进入下游环境、窃取备份数据或破坏恢复能力的供应链跳板；已部署 WebShell 意味着只升级或删除矿工不足以清除持久化。
- **建议行动：** 在厂商提供并验证修复前，将管理界面限制到可信 IP/VPN，禁止互联网直接访问。搜索 `MicrosoftEdgeUpdateSvc`、伪装的 `msedge.exe`、`Taskgmr.ps1`、JSP WebShell 和异常 Java 子进程；确认失陷时从可信备份完整重建主机、轮换平台及下游客户凭据，并审计备份读取、导出与删除记录。

  - [BleepingComputer：攻击链与最新受影响版本](https://www.bleepingcomputer.com/news/security/unpatched-ahsaycbs-flaws-exploited-to-deploy-webshells-mine-crypto/)
  - [NVD：CVE-2026-105133](https://nvd.nist.gov/vuln/detail/CVE-2026-105133)

### 3. 攻击者利用 Google 广告与 Bing 跳转投放假 Claude 安装器（72 小时扩展）

- **分类：** AI 工具仿冒 / ClickFix / 恶意广告
- **严重度：** 高
- **发布日期：** 2026-10-09
- **可信度：** 多方确认（Push Security 原始研究、独立媒体复核）
- **影响对象：** 搜索“Claude Mac”等关键词并通过广告安装 Claude 的 macOS 用户，尤其是开发者和拥有云端、代码仓库或 AI API 凭据的终端
- **发生了什么：** Push Security 发现一条被称为“Adception”的投放链：Google 搜索广告先使用可信的 Bing 搜索结果 URL，通过受控跳转与被攻陷网站将目标引向仿冒 Claude 下载页，并用多层隐藏机制规避广告审核和自动扫描。页面视觉上显示 Anthropic 的合法安装命令，但“复制”按钮会把另一条恶意命令写入剪贴板；该命令从攻击者域名下载数据并直接交给 macOS `zsh` 执行。研究发布时最终载荷仍未确定，因此不能断言已经投放某一种具体窃密软件。
- **为什么值得关注：** AI 编程工具常通过终端脚本快速安装，用户也习惯授予其源码、API 密钥和开发环境访问权。攻击链同时借用 Google、Bing 与 Claude 品牌的可信度，并利用“页面所见命令”和“剪贴板实际内容”不一致绕过人工检查。
- **建议行动：** 仅从 Anthropic 官方站点或受管软件渠道安装 Claude；粘贴前在纯文本编辑器检查完整命令，避免执行 `curl | bash/zsh` 形式的未知脚本。企业应拦截已知恶意域名及新注册仿冒域、监测终端从浏览器启动 shell 后的下载执行，并对运行过可疑命令的设备隔离取证、轮换浏览器会话、代码仓库令牌、云凭据和 AI API 密钥。
- **原始来源与补充来源：**
  - [Push Security：Adception 原始研究](https://pushsecurity.com/blog/adception-malvertising-another-search-engines-search-results)
  - [BleepingComputer：假 Claude 安装器攻击链](https://www.bleepingcomputer.com/news/security/hackers-abuse-google-ads-bing-redirects-to-push-claude-clickfix-attacks/)
